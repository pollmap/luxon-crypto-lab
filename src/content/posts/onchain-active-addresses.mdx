## 도입 — "네트워크 효과의 정량"

Robert Metcalfe (Ethernet 발명자) 가 1980년 발표한 "Metcalfe's Law" — "네트워크 가치 = N² (사용자 수의 제곱)". 통신 + 소셜 네트워크의 성장 모델.

이를 BTC 에 적용 — "BTC 시가총액 = N² (Active Addresses 의 제곱)".

## 1. Active Addresses

### 1-1. 정의
일 "sending address" 의 unique count. 같은 주소가 여러 트랜잭션 보내도 1 카운팅.

### 1-2. 시간 진화
| 시점 | 일 Active Addresses |
|------|-------------------|
| 2013.1 | ~50K |
| 2017.12 | ~1.1M |
| 2021.4 | ~1.0M |
| 2024.4 | ~1.2M |
| 2026.1 | **~1.4M** |

가속이지만 2017 후 "plateau". 이는 — "활성 사용자 수가 가격만큼 가속하지 않음" 의 신호.

## 2. Metcalfe's Law 적용

### 2-1. 회귀
<Formula>{`ln(Market Cap) = α + β × ln(Active Addresses)
β ≈ 1.92 (R² = 0.83, 2013-2024)`}</Formula>
β = 1.92 가 Metcalfe's "N² (β = 2)" 에 가깝습니다. 통계적으로 "Metcalfe's Law 가 BTC 에 부분 적용".

### 2-2. 2024-2026 deviation
2024 ETF 후 — Market Cap 가속이 Active Addresses 가속보다 빠름. β 가 점차 2.0 미만으로 감소. "기관 자금이 사용자 수보다 빠르게 시장 진입" 의 결과.

## 3. 한국 사용자 비중

한국 가상자산 사용자 약 800만 명 (2026 Q1). 글로벌 BTC 활성 사용자 (월) 약 8,000만 추정. 한국 비중 ~10%.

이 10% 가 한국 사용자의 "BTC 영향력". 글로벌 가격 결정의 작은 부분이지만 알트 시장에서는 16% (#O1).

## 4. 미해결 질문

### 4-1. "unique address" 정의
- 한 사용자가 여러 address 사용 → 인플레이션
- 거래소가 단일 address 처리 → 디플레이션

이 두 효과가 상쇄. 정확한 "사용자 수" 측정 어려움.

### 4-2. ETF 의 Active Addresses 영향
ETF 가 BTC 보유 시 — "ETF wallet 1개" 만 카운팅. 그러나 ETF 보유자는 수만 명. 이 효과로 Active Addresses 가 가격을 underestimate.

<Callout type="opposing-view" title="반대 시각 · Metcalfe's Law 의 BTC 적용 한계">
첫째, **β = 1.92 의 in-sample 결과**. Out-of-sample 검증 필요.

둘째, **2024 후 β < 2**. 패턴 변화.

셋째, **ETF 가 Active Addresses 를 deflate**. 가격과 사용자 수의 관계 변화.

이 비판이 의미 — Metcalfe's Law 가 "directional" 맞지만 "precise prediction" 어려움.
</Callout>

## 결론

1. **β = 1.92 (Metcalfe's N²에 가까움)**.
2. **2024 후 β 감소 — ETF 영향**.
3. **한국 사용자 ~10% 글로벌 점유**.
