## 1. 토크노믹스 (Tokenomics)

- **토크노믹스 (Tokenomics)** — 토큰 + 경제학. 토큰의 발행, 분배, 가치 포착 메커니즘 분석.
- **시가총액 (Market Cap)** — 유통량 × 가격. 가상자산의 *"기업 가치"* 비유.
- **유통량 (Circulating Supply)** — 시장에서 거래 가능한 토큰 수.
- **총 공급량 (Total Supply)** — 발행된 모든 토큰 (잠금 포함).
- **최대 공급량 (Max Supply)** — 영구 발행 가능한 한도. BTC 의 21M 이 대표 사례.
- **인플레이션 / 디플레이션 (Inflation / Deflation)** — 토큰 발행이 늘어나는지 (인플레이션) 줄어드는지 (디플레이션).
- **반감기 (Halving)** — 비트코인의 마이너 보상이 4년마다 반으로 줄어드는 메커니즘.
- **에어드랍 (Airdrop)** — 사용자에게 토큰을 무료 분배하는 마케팅.

## 2. 합의 (Consensus)

- **PoW (Proof of Work)** — 작업 증명. 비트코인이 채택. 마이너가 계산을 통해 합의.
- **PoS (Proof of Stake)** — 지분 증명. 이더리움이 The Merge 후 채택. 검증자가 ETH 스테이킹.
- **검증자 (Validator)** — PoS 에서 블록 생성 + 검증을 담당하는 entity.
- **스테이킹 (Staking)** — 검증자가 자기 토큰을 잠그고 블록 생성 권한 획득.
- **슬래싱 (Slashing)** — 검증자가 잘못된 행동 시 — 자기 스테이킹된 토큰 일부 몰수.
- **마이닝 (Mining)** — PoW 에서 채굴. 컴퓨터 계산으로 블록 생성.
- **51% 공격 (51% Attack)** — 단일 entity 가 — 네트워크 해시레이트의 51%+ 점유 시 공격 가능.
- **PBFT (Practical Byzantine Fault Tolerance)** — 분산 시스템의 합의 알고리즘 표준.

## 3. 온체인 메트릭 (On-chain Metrics)

- **NVT (Network Value to Transactions)** — 네트워크 가치 / 일일 거래량. 주식의 P/E 와 비슷한 framework.
- **MVRV (Market Value to Realized Value)** — 시가총액 / 실현가치 (Realized Cap). 사이클 정점/저점 판단.
- **Realized Cap** — 각 토큰이 마지막 이동된 시점의 가격 합. 사용자 평균 cost basis 근사.
- **HODL Waves** — 보유 기간별 코인 분포 시각화.
- **NUPL (Net Unrealized Profit/Loss)** — 미실현 손익 비율. 시장 심리 측정.
- **SOPR (Spent Output Profit Ratio)** — 코인 매도 시점의 수익률 측정.
- **Fear & Greed Index** — 시장 심리 지표 (0-100).
- **Hash Rate** — 비트코인 네트워크의 총 계산 능력.

## 4. 가치평가 (Valuation)

- **P/E (Price/Earnings)** — 주식의 가치평가. 가상자산에는 직접 적용 어려움.
- **P/F (Price/Fees)** — 가격 / 수수료 수익. 이더리움 가치평가에 사용.
- **P/S (Price/Sales)** — 가격 / 매출. DeFi 프로토콜 평가.
- **mNAV (modified Net Asset Value)** — Treasury 회사의 시가총액 / 보유 자산. Strategy 의 1.65x 등.
- **DCF (Discounted Cash Flow)** — 미래 현금흐름의 현재가치. 전통 가치투자.
- **Stock-to-Flow (S2F)** — 기존 공급 / 새 공급 비율. PlanB 모델로 유명.

## 5. DeFi (Decentralized Finance)

- **DeFi** — 탈중앙화 금융. 스마트 컨트랙트 기반 금융.
- **TVL (Total Value Locked)** — DeFi 프로토콜에 잠긴 자산 총량.
- **AMM (Automated Market Maker)** — 자동화된 시장 조성. Uniswap 의 x×y=k 공식.
- **CDP (Collateralized Debt Position)** — 담보부 부채 포지션. MakerDAO 의 framework.
- **Lending / Borrowing** — DeFi 대출 / 차용. Aave, Compound 의 주 사업.
- **Liquidation** — 청산. 차주의 담보가 임계값 아래로 떨어지면 자동 회수.
- **Slippage** — 슬리피지. 거래 시 예상 가격과 실제 가격의 차이.
- **Impermanent Loss (IL)** — 임시 손실. LP 가 가격 변동으로 입는 손실.

## 6. L2 (Layer 2)

- **L1 / L2** — 메인넷 (이더리움) / L2 (Arbitrum, Base 등).
- **Rollup** — 트랜잭션을 모아 메인넷에 게시하는 framework.
- **Optimistic Rollup** — *"기본 valid"* 가정 + 7일 challenge 기간.
- **ZK Rollup** — ZK proof 로 즉시 valid 검증.
- **Sequencer** — L2 에서 트랜잭션을 정렬 + 처리하는 entity.
- **Data Availability (DA)** — L2 데이터를 어디에 저장하는가. 이더리움 메인넷 또는 외부 layer.
- **EIP-4844 (Proto-Danksharding)** — L2 데이터 비용 절감 framework. *"Blob"* 도입.
- **Superchain** — Optimism + Base + 다수 OP Stack chain 의 통합 framework.

## 7. ZK (Zero-Knowledge)

- **ZK proof** — 자기가 진실을 알고 있다는 것을 — 진실 자체를 공개하지 않고 증명.
- **zkEVM** — ZK proof 로 검증 가능한 EVM.
- **PLONK / Halo2 / STARK** — ZK proof 알고리즘.
- **Type 1-4 zkEVM** — Vitalik 의 zkEVM 분류 (이더리움 호환도 기준).
- **Circuit** — ZK proof 가 계산되는 *"전기 회로"* 비유.

## 8. 스테이블코인 (Stablecoin)

- **스테이블코인 (Stablecoin)** — 가격 변동성이 적은 가상자산. USD 페그가 가장 많음.
- **Fiat-Backed** — USDC, USDT 같은 법정 통화 담보 스테이블코인.
- **Crypto-Backed** — DAI, USDS 같은 가상자산 담보.
- **Algorithmic** — Luna UST 같은 알고리즘 기반 (대부분 실패).
- **Depeg** — 스테이블코인이 1 USD 페그를 잃는 사건.
- **PSM (Peg Stability Module)** — DAI 의 USDC 와 1:1 교환 메커니즘.

## 9. NFT + RWA

- **NFT (Non-Fungible Token)** — 비대체성 토큰. 디지털 소유권.
- **ERC-721** — 이더리움 NFT 표준.
- **ERC-1155** — 다중 토큰 표준.
- **RWA (Real-World Asset)** — 실물자산 토큰화. BlackRock BUIDL 등.
- **STO (Security Token Offering)** — 토큰증권. 한국 자본시장연구원 표준.

## 10. 거래소 + 시장

- **CEX (Centralized Exchange)** — 중앙집중형 거래소. Binance, Coinbase, 업비트.
- **DEX (Decentralized Exchange)** — 분산 거래소. Uniswap, Curve.
- **Order Book** — 호가창. CEX 의 매칭 방식.
- **Liquidity Pool** — 유동성 풀. AMM 의 자산 풀.
- **Market Maker** — 시장 조성자. 호가 제공자.
- **Funding Rate** — Perp 시장의 펀딩 수수료.
- **Open Interest (OI)** — 미결제 약정 총량.

## 11. 거버넌스 + 보안

- **DAO (Decentralized Autonomous Organization)** — 탈중앙화 자율 조직.
- **Governance Token** — 거버넌스 토큰. UNI, AAVE 등.
- **veToken** — vote-escrowed token. Curve veCRV 모델.
- **Multisig** — 다중 서명. 자산 보호 framework.
- **Cold Wallet / Hot Wallet** — 콜드 / 핫 지갑. 보안 vs 편의 trade-off.
- **Self-Custody** — 자가 보관. 사용자가 직접 키 관리.
- **Hardware Wallet** — 하드웨어 지갑. Ledger, Trezor.
- **Seed Phrase** — 시드 구문. 12-24 단어 백업.

## 12. 매크로 + 정책

- **CBDC (Central Bank Digital Currency)** — 중앙은행 디지털화폐. e-CNY, 디지털 유로 등.
- **MiCA** — EU 가상자산 규제 (Markets in Crypto-Assets).
- **GENIUS Act** — 미국 스테이블코인 입법.
- **VAUPA** — 한국 가상자산이용자보호법.
- **Travel Rule** — 자금세탁방지를 위한 송수신자 정보 공유.
- **CARF** — OECD 가상자산 정보교환 framework.
- **AML / CFT** — 자금세탁방지 / 자금조달방지.
- **KYC** — 고객 신원확인.
