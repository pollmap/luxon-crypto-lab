## 도입 — *"L2 인프라의 두 모델"*

자, Optimism 강의를 시작합시다. L2 시장에서 — Optimism 이 Arbitrum 과 두 *"Optimistic Rollup leader"*. 그러나 — 두 회사의 전략이 매우 다릅니다.

- **Arbitrum (Offchain Labs)**: *"단일 체인 운영 + 자체 인프라"*. Princeton 학술 배경.
- **Optimism (OP Labs)**: *"OP Stack 오픈소스 + Superchain 생태계"*. 분산 인프라 비전.

이 두 다른 길이 — L2 시장의 두 학술 답입니다. 오늘은 — Optimism 의 *"OP Stack + Superchain"* framework 을 깊이 봅니다.

## 1. Optimism 의 출발

### 1-1. Plasma → Optimistic Rollup

Optimism 의 출발이 — Plasma (이더리움 L2 의 초기 framework). 2019-2020 — Vitalik Buterin 등이 Plasma 의 한계를 발견하고 *"Optimistic Rollup"* 으로 전환.

Optimism (이전 이름 *"Optimistic PBC"*) 이 — Optimistic Rollup 학술 framework 의 첫 구현 중 하나.

### 1-2. Optimism 메인넷

2021년 12월 — Optimism 메인넷 출시. Arbitrum (2021년 8월) 보다 약 4개월 늦음.

## 2. OP Stack — *"L2 의 오픈소스 프레임워크"*

### 2-1. OP Stack 가 무엇인가

OP Stack 이 — Optimism 이 개발한 L2 의 오픈소스 framework. 누구나 — OP Stack 으로 자기 L2 를 만들 수 있음.

OP Stack 채택 사례:
- Base (Coinbase L2)
- Worldchain (Worldcoin L2)
- Mode (DeFi 친화 L2)
- Zora (NFT 친화 L2)
- Fraxtal (Frax Finance L2)
- 다수 더 (50+ OP Stack chain)

### 2-2. 학술적 의미

OP Stack 이 — L2 시장의 *"공유 인프라 framework"*. 이게 학술적으로 매우 흥미로워요. 왜냐:

**전통적 L2 모델**:
- 각 L2 가 자체 인프라 개발
- 호환성 X
- 연결 어려움

**OP Stack 모델**:
- 공유 인프라
- 호환성 자동
- *"Superchain"* 으로 연결

이 framework 이 — Stanford CBR + Cornell IC3 의 학술 분석 활발 분야.

## 3. Superchain — *"OP Stack chain 의 통합"*

### 3-1. Superchain 비전

OP Stack chain 들이 모두 — *"Superchain"* 이라는 통합 framework 으로 연결.

Superchain 의 특징:
- 공유 보안 (이더리움 + Optimism)
- 공유 통신 (cross-chain message)
- 공유 인프라 (sequencer 인프라)
- 공유 거버넌스 (OP 토큰)

### 3-2. 학술적 의미

Superchain 이 — *"L2 의 다중 체인 통합 framework"*. 글로벌 L2 학계의 가장 흥미로운 학술 토론 주제.

비교 대상:
- Cosmos (다중 체인 + IBC) — 아키텍처 유사
- Polkadot (parachain) — 거버넌스 다름
- Avalanche subnet — 보안 모델 다름

Superchain 이 — 이 다중 체인 framework 들의 *"이더리움 친화 버전"* 입니다.

## 4. Retroactive Funding — *"공공재 자금 조달의 학술 framework"*

### 4-1. Retroactive Funding 가 무엇인가

Optimism 의 가장 학술적 혁신 — *"Retroactive Public Goods Funding (RPGF)"*.

작동:
- Optimism 이 — 이미 가치를 만든 공공재 (오픈소스 도구, 인프라, 교육) 에 사후 자금 지원
- 사용자 + 개발자가 — 공공재 가치를 평가
- OP 토큰으로 보상 분배

### 4-2. 학술적 의미

이게 학술적으로 매우 중요합니다. *"공공재 자금 조달"* 이 — 글로벌 경제학의 가장 어려운 문제 중 하나거든요.

전통 framework:
- 정부가 — 사전에 공공재 선정 + 자금 지원
- 시장에서 결정 어려움

Retroactive Funding:
- 시장이 — 사후에 공공재 가치를 평가
- 자금 분배가 — 공정 + 효율

이 framework 이 — Vitalik Buterin + Glen Weyl (RadicalxChange) 의 학술 글로 발전. *"공공재 자금 조달의 학술 표준"* 후보.

### 4-3. RPGF 시행 결과

Optimism 이 — 4 라운드의 RPGF 시행 (2022-2024). 총 약 $500M+ 가 공공재에 분배.

주요 수혜자:
- Ethereum 클라이언트 개발자 (Geth, Erigon)
- Optimism + L2 도구 개발자
- 학술 연구자 + 교육자
- Open source DeFi 프로젝트

이게 — *"분산 거버넌스의 자금 분배"* 학술 사례.

## 5. OP 토큰 — *"가치 포착 + 거버넌스"*

### 5-1. OP 의 역할

OP 토큰 (2022년 출시):
- Optimism + Superchain 거버넌스
- RPGF 자금 분배 결정
- Optimism Collective 의 회원 자격

### 5-2. 가치 포착의 학술적 분석

OP 가 — Cong et al. (2021) RFS framework 으로 분석:
- 사용 가치: 거버넌스 + RPGF 참여
- 투자 가치: 시장 가격
- 두 가치의 결합

그러나 — UNI, COMP 처럼 *"실질 수익 분배"* 가 약함. 거래 수수료 분배 X.

### 5-3. Sequencer 수익 + RPGF

Optimism 의 sequencer 수익이 — RPGF 로 분배. 즉, 시스템 수익이 — 공공재로 환원. 이게 학술적으로 *"분산 자본주의 모델"* 의 사례.

## 6. Optimism vs Arbitrum

### 6-1. 두 모델의 비교

| 차원 | Optimism | Arbitrum |
|------|--------|--------|
| 모델 | 분산 인프라 (OP Stack) | 단일 체인 |
| Superchain | 핵심 비전 | X |
| RPGF | 핵심 framework | X |
| 토큰 | OP | ARB |
| 시장 점유 | 작음 (단일 체인) | 1위 |
| 학술적 영향 | 매우 큼 (framework) | 큼 (구현) |

### 6-2. 두 학술 답

Optimism + Arbitrum 이 — Optimistic Rollup 의 두 학술 답:
- Optimism: *"공유 인프라 + 공공재"*
- Arbitrum: *"단일 체인 + 자체 인프라"*

학술적으로 — 둘 다 의미 있음. 실제 시장 결과는 미정.

## 7. Optimism 의 시장 위상

### 7-1. TVL + 사용자

- Optimism 단일 체인 TVL: 약 $1-2B
- OP Stack 전체 (Base + Worldchain + 등) TVL: 약 $10-15B
- Superchain 합계가 — Arbitrum 보다 큼

### 7-2. 학술적 영향

Optimism 의 OP Stack + RPGF 가 — L2 학계의 가장 영향력 있는 framework 중 하나. 글로벌 학술 분석 활발.

<Callout type="opposing-view" title="반대 시각 · Optimism 의 *분산성 약화*">
Optimism 의 비판:

첫째, ***"단일 체인 점유 작음"***. OP Stack 전체로는 크지만, Optimism 단독은 Arbitrum 의 1/3.

둘째, ***"OP 토큰 가치 포착 약함"***. ARB 보다도 가치 포착 메커니즘 약함.

셋째, ***"Sequencer 중앙화"***. Optimism + Base + 다수 OP Stack chain 의 sequencer 가 모두 단일 entity 운영.

넷째, ***"RPGF 의 거버넌스 위험"***. 공공재 가치 평가가 — 정치적 + 인기 영향.

이 비판이 의미하는 바 — Optimism 이 *"L2 학술 framework"* 으로는 매우 가치 있되, *"실용 시장 점유"* 는 Arbitrum 에 밀림.
</Callout>

## 결론

1. **Optimism = L2 의 분산 인프라 framework, OP Stack**.
2. **OP Stack = 공유 인프라, 50+ chain 채택**.
3. **Superchain = 다중 L2 통합 framework**.
4. **Retroactive Funding = 공공재 자금 조달의 학술 표준 후보**.
5. **OP 토큰 = 거버넌스 + RPGF, 가치 포착 약함**.
