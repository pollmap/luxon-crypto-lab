## 1. Ocean Protocol — Compute-to-Data

### 1-1. 메커니즘
*"데이터 자체"* 를 공유 X. 대신 *"AI 모델이 데이터에 접근해 학습"* 만 허용. Ocean 토큰이 결제 수단.

### 1-2. 사용 사례
- 의료 데이터 (개인정보 보호 필수)
- 금융 데이터 (Numerai 와 결합)
- 산업 IoT 데이터

### 1-3. 시총
2026 Q1 OCEAN 시총 ~$0.6B. 작은 규모.

## 2. Numerai (NMR)

### 2-1. 메커니즘
*"헤지펀드 toner먼트"*. 데이터 과학자가 — Numerai 의 anonymous 금융 데이터로 ML 모델 학습. 모델 예측을 NMR 토큰 stake. 정확한 예측 시 보상.

### 2-2. 시총
2026 Q1 NMR 시총 ~$0.2B.

### 2-3. 학술 의의
*"분산 데이터 과학 + 금융 예측"* 의 학습 사례. AI + 가상자산의 교차.

## 3. Bittensor 서브넷

### 3-1. 메커니즘
Bittensor (#A1) 의 78 서브넷 중 일부가 데이터 위주 — *"text embedding"*, *"image dataset"* 등.

### 3-2. 학술 평가
Bittensor 의 데이터 서브넷이 진정한 *"data marketplace"* 인지 — 학계 검증 진행 중.

<Callout type="opposing-view" title="반대 시각 · 데이터 토큰의 한계">
