## 데이터의 자산화라는 명제

AI 산업의 가장 큰 병목은 모델 아키텍처도, 컴퓨팅 자원도 아닌 학습용 데이터의 확보 비용이다. OpenAI 가 GPT-4 학습에 사용한 텍스트 데이터셋이 대략 13조 토큰 규모로 추정되며, Common Crawl 외에도 Reddit, Twitter, 학술 논문, 출판물, 사용자 대화 로그가 포함된 것으로 알려져 있다. 2023년 이후 Reddit 이 자체 API 의 유료화를 단행하고 The New York Times 가 OpenAI 를 상대로 저작권 소송을 제기한 사건은, 데이터가 더 이상 무료로 채굴되는 자원이 아니라 명시적인 라이선스 시장을 형성한다는 신호였다.

데이터를 거래 가능한 자산으로 만드는 작업은 AI 산업이 직면한 현실적 과제다. 구글, 메타, OpenAI 같은 대형 사업자는 자체 데이터 풀을 보유하거나 사후적 대규모 라이선스 계약을 체결할 수 있지만, 신생 기업이나 개별 연구자는 양질의 데이터에 접근할 통로가 제한적이다. 동시에 데이터 보유자(병원, 금융기관, 산업 IoT 운영자) 입장에서는 보안과 규제 부담 때문에 데이터를 외부로 이전하는 것 자체가 불가능에 가깝다. 이 양면 시장의 마찰을 줄이기 위한 시도가 가상자산 영역에서 등장한 데이터 토큰의 출발점이다.

가상자산 기반 데이터 마켓플레이스를 표방하는 프로젝트는 크게 세 가지 갈래로 분류된다. 첫째, 데이터 자체를 옮기지 않고 모델이 데이터에 접근하도록 허용하는 방식의 Ocean Protocol. 둘째, 헤지펀드의 익명화된 시장 데이터를 라이선싱한 뒤 데이터 과학자에게 토너먼트 형태로 제공하고 예측 정확도에 따라 보상하는 Numerai. 셋째, 인공지능 모델 자체를 서브넷 단위로 운영하면서 데이터 제공자, 검증자, 채굴자에게 토큰 보상을 분배하는 Bittensor 다. 본문에서는 이 세 갈래의 메커니즘과 시장 위치, 그리고 한계를 차례로 살핀다.

## Ocean Protocol — Compute-to-Data 라는 발상

Ocean Protocol 은 2017년 Trent McConaghy 가 BigchainDB 의 후속으로 시작한 프로젝트다. 핵심 아이디어는 단순하다. 의료 영상이나 거래소 주문장 같은 민감 데이터를 외부에 공개하지 않으면서도 AI 모델 학습이 가능하도록, 데이터를 옮기지 않고 모델만 데이터 보관소로 보내는 구조를 채택한 것이다. 이를 Compute-to-Data(C2D) 라 부른다.

C2D 의 동작 흐름은 데이터 게시자, 알고리즘 게시자, 검증 노드의 3자 구도로 구성된다. 데이터 보유자는 자신의 데이터셋을 ERC-721 형태의 데이터 NFT 로 토큰화한 뒤, 접근 권한을 ERC-20 형태의 데이터 토큰으로 분할 발행한다. 모델 개발자는 OCEAN 토큰으로 데이터 토큰을 구매하고, 자신의 학습 코드를 데이터 보관소가 운영하는 격리된 컴퓨팅 환경에 제출한다. 학습은 데이터 보관소 내부에서 수행되고, 외부로 반출되는 것은 학습 결과물(파라미터, 메트릭) 뿐이다. 이 구조 위에서 데이터는 항상 원소유자의 통제 아래 머물고, 알고리즘은 결과만 가지고 돌아온다.

이 방식의 학술적 의의는 분명하다. 정보 공개 없이 통계적 학습이 가능한 differential privacy, federated learning, secure multi-party computation 의 흐름과 직접 맞닿아 있기 때문이다. Ocean 자체는 동형암호나 secure enclave(예: Intel SGX) 와 같은 하드웨어 기반 보안 기법을 직접 구현하지는 않지만, 이런 기법을 적용한 노드 운영자에게 추가적인 보상을 분배할 수 있는 토큰 인센티브 레이어를 제공한다.

시장 측면에서 Ocean Protocol 의 한계도 명확하다. 2026년 1분기 기준 OCEAN 의 시가총액은 6억 달러 내외에 머물러 있고, 누적 거래된 데이터셋 수는 수만 건 수준에 그친다. 글로벌 AI 데이터 시장 전체 규모가 IDC 추정으로 2025년 약 750억 달러에 도달한 것과 비교하면, Ocean 이 점유한 비중은 0.1% 미만이다. 의료, 자율주행, 금융 같은 고가치 데이터 영역에서는 이미 IBM Watson Health, Tempus, Refinitiv 같은 전통 사업자가 자리 잡고 있고, 이들은 가상자산 기반 결제를 도입할 유인이 약하다. Ocean 의 사용자 풀은 학술 연구자와 헬스케어 스타트업에 한정되어 있으며, 실질적 거래량 또한 OCEAN 토큰 자체의 가격 변동과 거의 동조한다.

다만 Ocean 의 설계 자체가 갖는 의의는 여전하다. 데이터 거래의 본질적 어려움 — 한 번 공개된 데이터는 가격을 매길 수 없게 된다는 정보재의 특성 — 을 데이터를 공개하지 않은 채 거래하는 방식으로 우회한다는 점에서, 적어도 개념상으로는 정보재 시장의 가장 오래된 난제를 정면으로 다룬다. 이 발상은 Federated Learning 을 채택한 기업 컨소시엄(Google Health, Owkin 등) 으로도 확산되었으며, 가상자산이라는 정산 수단을 사용하지 않더라도 그 설계 원리는 살아남는 추세다.

## Numerai — 익명화된 시장 데이터의 토너먼트

Numerai 는 2015년 Richard Craib 가 설립한 헤지펀드로, 처음부터 가상자산 회사로 출발한 것이 아니다. Numerai 의 본업은 quantitative equity hedge fund 이고, AUM 은 2024년 기준 약 4억 달러 수준으로 알려져 있다. NMR 토큰은 이 헤지펀드의 부산물에 해당하지만, 데이터 토큰의 가장 성공한 실험 사례 중 하나로 자주 인용된다.

Numerai 의 메커니즘은 다음과 같이 구성된다. Numerai 본사는 자체 보유한 글로벌 주식 데이터에 정규화와 익명화를 가한 뒤, 데이터 과학자에게 무료로 배포한다. 데이터셋의 각 컬럼은 의미가 명시되지 않은 상태로 제공되며, 어떤 종목인지, 어느 국가인지, 어떤 팩터인지조차 알 수 없도록 가공되어 있다. 데이터 과학자는 이 익명 피처를 활용해 미래 수익률에 대한 예측 모델을 학습하고, 매주 새로운 라이브 데이터셋에 대해 예측치를 제출한다. 제출 시점에는 자신이 신뢰하는 정도에 따라 NMR 토큰을 stake 한다.

예측이 시장 수익률 대비 양의 정보비율을 기록하면 stake 한 NMR 이 보너스와 함께 반환되고, 음의 정보비율을 기록하면 stake 가 burn 된다. 이 burn-and-mint 구조는 Numerai 헤지펀드 입장에서 모델의 우수성에 대한 일종의 신뢰 가격을 시장에서 직접 받아내는 도구가 된다. 헤지펀드는 다수 데이터 과학자가 제출한 예측을 메타 모델로 결합한 뒤, 실제 운용 자본으로 시장에 진입한다.

Numerai 가 실험으로서 흥미로운 것은, 데이터 자체를 무료로 풀고 예측 결과에만 가격을 매긴다는 역설적 구조다. 전통적 데이터 시장에서는 데이터 보유자가 데이터를 팔지만, Numerai 에서는 데이터 보유자가 데이터를 공급하고 그 데이터를 활용한 예측 능력을 사들인다. 이 구조는 Kaggle 의 머신러닝 경진대회와 닮았지만, 보상 수단이 토큰화되어 있고 정확도에 따른 burn 메커니즘이 추가되었다는 차이가 있다.

NMR 시가총액은 2026년 1분기 기준 2억 달러 내외이며, 이는 Numerai 헤지펀드의 AUM 보다 작다. 토큰 가격은 헤지펀드의 운용 성과보다는 Numerai 토너먼트에 참여하는 데이터 과학자 수, 그리고 stake 압력의 변동에 따라 움직이는 경향이 강하다. 2020년 이후 누적 참가자 수는 수만 명에 도달했고, 이 가운데 수천 명이 정기적으로 모델을 제출한다. 이 참가자 풀의 두께가 Numerai 가 실험을 지속할 수 있는 자원이지만, 2023년 이후 ChatGPT 와 LLM 기반 코딩 도구가 보급되면서 단순 모델 제출은 점점 commoditize 되는 추세다. Numerai 측은 이에 대응해 Numerai Signals 라는 별도 토너먼트를 신설하고, 외부 데이터 추가를 유도해 왔다.

Numerai 의 가장 큰 한계는 단일 헤지펀드의 단일 자산군(미국 대형주 중심) 에 묶여 있다는 점이다. 다양한 자산군이나 다양한 운용사가 동일한 메타 모델 인프라를 공유하는 구조로 확장하지 못한다면, NMR 의 경제 가치는 Numerai 회사 자체의 운명과 동조한다. 분산된 헤지펀드 데이터 시장이라는 비전은 매력적이지만, 실제 자본시장에서 운용사들이 자신들의 모델 신호를 공동 풀에 공급할 유인이 충분하지 않다는 점에서 확장성이 제한된다.

## Bittensor — 서브넷이라는 분산 AI 시장

Bittensor 는 2021년 Jacob Steeves(Const) 와 Ala Shaabana(Unconst) 가 발표한 프로젝트로, 백서 단계에서는 단일 네트워크 위에서 분산 AI 모델을 협업 학습시킨다는 매우 야심찬 구상이었다. 2023년 dynamic TAO 업그레이드, 그리고 2024년 서브넷 토큰화 업그레이드를 거치면서 현재의 구조 — 다수의 서브넷이 각자의 AI 태스크를 운영하고, 메인넷 TAO 가 서브넷 간 자원 배분을 조정하는 다층 토큰 경제 — 가 정착했다.

Bittensor 의 하부 단위인 서브넷은 특정 AI 태스크에 최적화된 작은 네트워크다. 각 서브넷에는 데이터 제공자(채굴자) 와 검증자가 존재한다. 채굴자는 서브넷이 정의한 작업 — 텍스트 생성, 이미지 생성, 음성 합성, 시계열 예측, 데이터 라벨링 등 — 을 수행한 결과물을 검증자에게 제출하고, 검증자는 결과물의 품질을 평가한다. 이 평가 점수는 Yuma Consensus 라는 독자적 합의 메커니즘을 통해 다른 검증자들의 점수와 비교, 가중 평균된 뒤 서브넷 토큰의 분배 비율을 결정한다.

서브넷 토큰은 개별 서브넷 안에서 통용되며, 메인넷 TAO 와는 자동시장조성자(AMM) 풀을 통해 교환된다. 다이내믹 TAO 라 불리는 이 메커니즘 아래에서, 시장이 어떤 서브넷에 더 많은 가치가 있다고 판단하면 그 서브넷 토큰의 가격이 오르고, 결과적으로 그 서브넷에 할당되는 TAO 의 양도 늘어난다. 즉, 서브넷 단위의 자원 경쟁이 토큰 가격 신호로 자동 조정된다는 것이 Bittensor 의 설계다.

2026년 1분기 기준 활성 서브넷 수는 60개를 넘었으며, 이 중 데이터와 직접 관련된 서브넷이 다수를 차지한다. 예를 들어 SN 3(Templar) 는 분산 학습용 데이터 라벨링, SN 13(Data Universe) 은 웹 크롤링 데이터 풀, SN 19(Vision) 은 컴퓨터 비전용 학습 데이터셋을 다룬다. 채굴자가 제공한 데이터의 품질은 검증자의 다층 평가 — 노이즈 비율, 라벨 정확도, 라이선스 유효성 — 를 거쳐 보상으로 전환된다. 이 흐름이 안정적으로 작동하면 데이터 라벨링이라는 노동집약적 산업의 일부를 토큰 인센티브로 분산 처리할 수 있다는 가설이다.

TAO 시가총액은 2026년 1분기 기준 약 30억 달러 내외로, 가상자산 AI 섹터에서 상위에 위치한다. 그러나 시장이 평가하는 것은 Bittensor 가 실제로 운영하는 AI 서비스의 매출이 아니라, 향후 분산 AI 인프라 시장이 형성될 경우 메인넷 토큰이 가질 수 있는 가치 저장 기능에 가깝다. 현재까지 Bittensor 서브넷이 만들어내는 결과물은 외부 사용자가 직접 결제하고 사용하는 상용 API 의 형태가 아니라, 대부분 자체 토큰 인센티브로 유지되는 자기 참조적 경제다. 이 한계는 Bittensor 자체도 인지하고 있고, 외부 수요가 진입하는 서브넷(예: SN 5 의 OpenKaito 검색 서비스, SN 4 의 텍스트 생성 모델 추론) 의 비중을 늘리기 위한 노력이 진행 중이다.

## 글로벌 AI 데이터 시장과 가상자산 데이터 시장의 규모 비교

AI 데이터 시장의 전체 규모를 가늠하기 위해 몇 가지 추정치를 정렬해 본다. 시장조사기관 IDC 는 2025년 글로벌 데이터 라벨링 및 큐레이션 시장 규모를 약 250억 달러로 보고했다. 여기에 학술 데이터 라이선스, 출판 데이터 라이선스, 의료 영상 데이터 거래, 자율주행 학습용 데이터 패키지 시장을 모두 포함하면 그 규모는 750억 달러 수준으로 확대된다. Statista 는 2030년까지 이 시장이 1,750억 달러를 넘어설 것으로 전망한다.

이에 비해 가상자산 기반 데이터 시장의 합산 시가총액은 OCEAN, NMR, TAO 와 그 주변 서브넷 토큰을 모두 합쳐도 100억 달러 미만이다. 시가총액과 시장 규모는 직접 비교 가능한 지표가 아니지만, 적어도 가상자산 기반 데이터 시장이 전통 데이터 시장의 1% 미만에 해당하는 규모에서 작동한다는 점은 분명하다. 거래 빈도, 라이선스 계약 수, 누적 매출 같은 보다 직접적인 지표로 비교해도 격차는 더 벌어진다.

이 격차의 가장 큰 요인은 규제와 신뢰의 문제다. 의료 데이터를 활용해야 하는 제약사는 HIPAA, GDPR, 의료법의 규제를 충족하지 못하는 데이터 소스에서 학습 데이터를 조달할 수 없다. 금융 데이터를 사용하려는 트레이딩 회사는 SEC 규제, FINRA 규제, 그리고 데이터 소유권 분쟁의 위험을 감수할 수 없다. 가상자산 기반 데이터 마켓이 이런 영역에 본격 진입하려면, 토큰 인센티브 외에도 라이선스 계약 구조, 감사 가능성, 분쟁 해결 체계가 갖추어져야 한다. 이는 기술 문제라기보다는 제도와 시장 신뢰의 문제다.

## 데이터 라벨링과 토큰 인센티브의 결합 가능성

데이터 시장의 부분집합으로서 데이터 라벨링 산업은 가상자산 기반 보상이 가장 직접적으로 적용될 수 있는 영역이다. 글로벌 데이터 라벨링 시장은 2025년 기준 약 50억 달러 규모이며, Scale AI, Appen, Labelbox, Sama 같은 사업자가 시장을 분점하고 있다. 이 시장의 주된 구조는 미국과 유럽의 AI 기업이 데이터셋을 발주하고, 인도, 필리핀, 케냐, 베네수엘라 등의 인간 라벨러가 시간당 1~3 달러 수준의 수당을 받고 라벨을 다는 형태다.

이 구조는 두 가지 마찰을 안고 있다. 첫째, 라벨러에 대한 보상 지급이 PayPal, 송금 서비스, 현지 은행을 거쳐야 하므로 결제 비용과 시간이 크다. 둘째, 라벨 품질에 대한 검증이 발주처와 라벨링 업체의 폐쇄적 절차에 의존하기 때문에, 동일한 라벨러가 여러 발주처를 옮겨다닐 때 평판이 누적되지 않는다.

Bittensor 의 데이터 라벨링 관련 서브넷, 그리고 Sapien 같은 가상자산 기반 데이터 라벨링 프로젝트는 이 두 마찰을 모두 토큰 결제로 풀어보려 한다. 라벨러의 보상은 즉시 토큰으로 지급되며, 라벨 품질에 대한 검증자 평가가 온체인에 누적되어 평판으로 작동한다. 결제 비용은 가스비 수준으로 줄어들고, 평판은 휴대 가능해진다.

이 구조의 약점은 토큰 가격 변동이다. 라벨링 노동의 시급을 토큰으로 지급할 경우, 토큰 가격이 30% 빠지면 실질 시급도 30% 빠진다. 이를 회피하기 위해 USDC 같은 스테이블 결제를 도입하면 가상자산이 가지는 결제 즉시성의 이점은 살아남지만, 평판 시스템의 가치는 결국 별도의 거버넌스 토큰으로 분리된다. 즉, 토큰 인센티브가 라벨링 시장에 도입되더라도 라벨링 자체의 보상은 결국 안정 통화로 회귀하는 경향이 나타난다.

## 한국 AI/데이터 산업과의 결합 가능성

한국의 AI 산업은 정부 주도의 데이터 댐(Data Dam) 사업을 거쳐 공공 데이터, 의료 데이터, 산업 데이터의 표준화가 일정 수준 진행되어 있다. AI Hub 는 한국지능정보사회진흥원이 운영하는 학습용 데이터 공유 플랫폼으로, 누적 데이터셋 수가 1,000건을 넘었다. 이 가운데 한국어 자연어처리, 음성 인식, 의료 영상 데이터셋은 국제적으로도 희소성이 높은 자원이다.

문제는 이 데이터가 가상자산 기반 마켓플레이스로 흘러갈 유인이 거의 없다는 점이다. 공공 데이터는 무료 또는 낮은 가격으로 배포되며, 한국정보화진흥원이 외부 결제 수단을 도입할 정책적 동기가 약하다. 의료 데이터는 개인정보보호법과 의료법의 이중 규제 아래 있어, 토큰화된 거래는커녕 일반적인 라이선스 거래도 제한적이다.

다만 한국 시장에서 가상자산 데이터 토큰이 의미를 가질 수 있는 영역이 두 군데 있다. 첫째, 한국어 LLM 학습 데이터의 라벨링이다. KT, NAVER, 카카오, 그리고 Upstage, NCSOFT 같은 사업자가 자체 LLM 을 개발하면서 한국어 라벨링 수요가 빠르게 늘었다. 이 라벨링을 글로벌 토큰 기반 마켓플레이스에서 조달할 경우, 한국어 화자가 한국어 데이터를 라벨하면서 글로벌 결제 인프라를 활용할 수 있다. 이는 한국 사용자가 글로벌 데이터 노동시장에 참여하는 통로가 될 수 있다.

둘째, K-콘텐츠 라이선스 데이터다. 한국의 음악, 드라마, 웹툰, 게임 데이터는 글로벌 학습 데이터 풀에서 점점 비중이 커지고 있다. 이 콘텐츠의 학습 라이선스를 토큰화해 분배하는 시도는 기술적으로 가능하다. 다만 저작권 관리는 한국음악저작권협회, 한국방송작가협회, 한국문학예술저작권협회 등 기존 단체가 강하게 통제하고 있어, 가상자산 기반 라이선스가 이 단체들과 어떻게 공존할지가 관건이다.

가장 현실적인 진입 경로는 산업 IoT 데이터다. 자동차, 조선, 반도체 공정의 센서 데이터는 한국 제조업의 핵심 자산이며, 외부에 판매되기보다는 내부에서만 활용되어 왔다. Compute-to-Data 방식은 이 데이터를 외부에 공개하지 않으면서도 외부 모델 학습이 가능하도록 한다는 점에서, 제조업 데이터의 익명 라이선싱이라는 새로운 시장을 열 가능성이 있다. 다만 이 가능성이 실제 시장으로 이어지려면 산업통상자원부 차원의 표준화와 보안 인증이 선행되어야 한다.

## 데이터 토큰의 학술적 위치

데이터 토큰을 둘러싼 가장 흔한 비판은 두 가지다. 첫째, 데이터 자체에 가격을 매기는 것은 정보재의 본질상 불가능하므로 토큰화는 가격 신호 왜곡만 만든다는 비판. 둘째, 토큰 인센티브가 라벨러나 데이터 제공자의 행동을 왜곡해 데이터 품질이 오히려 떨어진다는 비판이다.

첫 번째 비판에 대해서는 Compute-to-Data 가 부분적 답을 제공한다. 데이터 자체에 가격을 매기는 대신 데이터 접근 비용에 가격을 매기는 방식이기 때문이다. 다만 이 답이 모든 정보재 영역에 일반화되지는 않는다. 텍스트, 이미지처럼 일단 모델에 입력되면 학습 결과물이 사실상 데이터의 사본 역할을 하는 영역에서는 C2D 의 보호 효과가 약하다.

두 번째 비판은 더 심각하다. Numerai 가 burn-and-mint 메커니즘을 도입한 이유 중 하나는, 토큰 보상만으로는 데이터 과학자들이 노이즈 모델을 대량 제출해 보상 풀을 희석시키는 행동을 막을 수 없었기 때문이다. Bittensor 의 Yuma Consensus 도 검증자들이 짜고 부정 평가를 내릴 가능성에 대비한 다층 가중 평균 구조다. 토큰 인센티브가 자동으로 양질의 데이터를 끌어내는 것은 아니며, 인센티브 설계의 정교함이 시스템의 결과 품질을 좌우한다.

학술 영역에서는 Princeton 의 Arvind Narayanan 그룹, Stanford 의 Emma Pierson 그룹이 데이터 토큰 메커니즘에 대한 정량 연구를 진행 중이다. NeurIPS 2024 에서 발표된 "Data Marketplaces with Quality Heterogeneity" 같은 논문은, 데이터 품질이 이질적일 때 토큰 보상이 균형 가격으로 수렴하기 어렵다는 이론적 결과를 보여준다. 즉, 데이터 토큰은 동질적 데이터(예: 정형화된 라벨링 작업) 에서는 작동하지만, 이질적 데이터(예: 의료 영상, 자율주행 시나리오 데이터) 에서는 균형 자체가 형성되지 않을 수 있다.

이 결과는 데이터 토큰이 만능 해법이 아니라는 점을 분명히 한다. 그러나 동시에, 동질적 라벨링 작업과 익명 통계 데이터 영역에서는 토큰 인센티브가 기존 결제 인프라보다 효율적일 수 있다는 가능성도 함께 보여준다. 이 두 가지 결론을 함께 받아들이는 것이 데이터 토큰이라는 실험을 평가하는 균형 잡힌 출발점이다.

## 결론을 가름하는 두 가지 질문

데이터 토큰이 지속 가능한 시장을 형성할지를 가늠하는 두 가지 질문은 다음과 같다. 첫째, 가상자산이 아닌 결제 수단(스테이블, 신용카드, 달러 송금) 으로도 동일한 인센티브 구조를 만들 수 있는가. 둘째, 데이터 보유자와 데이터 사용자 양측의 거래 비용을 토큰 인프라가 실제로 줄이는가.

첫 번째 질문에 대해 현재 시점에서의 답은 "부분적으로 가능하다"다. Numerai 의 토너먼트 구조는 USDC 결제로도 동일하게 작동할 수 있고, 라벨링 마켓도 마찬가지다. 그러나 burn-and-mint 같은 메커니즘은 토큰이라는 추상적 단위 위에서만 자연스럽게 구현되며, 일반 통화로 이를 모사하려면 별도의 에스크로 구조가 필요하다.

두 번째 질문에 대한 답은 영역마다 다르다. 글로벌 라벨링 시장처럼 결제 마찰이 큰 영역에서는 토큰 인프라가 거래 비용을 분명히 줄인다. 의료, 금융처럼 규제 부담이 큰 영역에서는 토큰 인프라가 오히려 추가적인 규제 위험을 만들어내며, 거래 비용을 줄이지 못한다. 이 영역별 격차가 데이터 토큰 시장의 미래 모습을 결정할 것이다.

데이터 토큰의 비판적 시각은 이 시장이 본질적으로 토큰 가격 변동성에 의존하는 자기 참조적 경제이며, 외부 수요가 진입하지 않는 한 토큰 보상이 실제 데이터 품질을 보장하지 못한다는 것이다. NY Federal Reserve 의 Antoine Martin 은 2024년 보고서에서 가상자산 기반 데이터 마켓의 거래량 대부분이 토큰 보상 분배 자체에서 발생하며, 외부 사용자의 결제로 발생한 매출은 1% 미만이라고 지적했다. 이 견해에서 보면 데이터 토큰은 새로운 시장을 만든다기보다 기존의 데이터 노동을 토큰화된 게임 내 재화로 옮긴 것에 가까우며, 시장이 성숙할수록 안정 통화 결제로 회귀할 것이라는 회의론이 따른다.
