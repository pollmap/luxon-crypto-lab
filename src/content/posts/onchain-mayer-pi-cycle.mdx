## 도입 — *"DMA 의 학술 표준"*

전통 주식 시장에서 *"200 DMA (Daily Moving Average, 일 이동평균)"* 가 long-term trend 의 표준. 이를 BTC 에 적용한 framework — Mayer Multiple + Pi Cycle.

## 1. Mayer Multiple

### 1-1. 정의
```
Mayer Multiple = 현재 BTC 가격 / 200 DMA
```

### 1-2. 임계
- < 1.0 = 200 DMA 미만 (저평가)
- 1.0 - 2.0 = 정상
- 2.0 - 2.4 = 가속
- > 2.4 = 고평가 (top zone)

### 1-3. 4 사이클 검증
| 시점 | Mayer | 결과 |
|------|-------|------|
| 2013.4 | 3.2 (top) | -75% 폭락 |
| 2017.12 | 3.8 (top) | -84% |
| 2021.4 | 2.9 (top) | -50% |
| 2024.3 | 1.8 | 일시 조정 |
| 2026.1 | 1.4 | 정상 |

## 2. Pi Cycle Top

### 2-1. 정의
2 DMA 의 cross 시점:
- **350 DMA × 2** (350일 이동평균 × 2)
- **111 DMA** (111일 이동평균)

이 둘이 cross 시점이 *"BTC 사이클 정점"* 신호.

### 2-2. 4 사이클 검증
| 시점 | Pi Cycle Cross | 결과 |
|------|----------------|------|
| 2013.4.9 | Cross | 2일 후 정점 |
| 2017.12.17 | Cross | 정점 |
| 2021.4.12 | Cross | 정점 |
| 2024.4 | 미발생 | 진정한 사이클 정점 X (또는 분할 정점) |

3 사이클 정점에서 Pi Cycle 이 정확하게 cross. 매우 유명한 trading signal 이 됐습니다.

### 2-3. 2024-2026 의 Pi Cycle 부재
2024-2026 사이클에서 Pi Cycle 이 cross 하지 않음. 이는 — *"이번 사이클 정점 미도달"* 또는 *"패턴 변화"*.

## 3. 한국 시장 적용

Mayer Multiple 과 Pi Cycle 이 글로벌 BTC 가격 기준. 한국 (김치 프리미엄 +5%) 보정 시 — Mayer Multiple 이 약간 낮게 측정. 한국 사용자가 글로벌 신호 그대로 사용 가능.
