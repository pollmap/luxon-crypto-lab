2021 거품 + 2022-2023 침체 후 NFT 시장이 어떻게 회복하고 있는지 학술 분석. OpenSea, Blur, Magic Eden 의 학술 위치.
</Callout>

## 1. NFT 시장의 4 단계

- **2017-2020**: 학술 framework 형성 (CryptoPunks, ERC-721)
- **2021**: 거품 (월 거래량 ~$5B+)
- **2022-2023**: 침체 (-95%)
- **2024-2026**: 회복 + 정착 (월 거래량 ~$0.5-1B)

## 2. 마켓플레이스 3 강자

### 2-1. OpenSea

- 글로벌 1위 NFT 마켓 (2017-)
- 시장 점유 약 30-40% (2026)
- 사용자 친화 + 다양한 NFT 지원

### 2-2. Blur

- 2022 출범, 빠르게 부상
- 전문 트레이더 친화 (벌크 거래)
- BLUR 토큰 보상으로 사용자 유치
- 시장 점유 약 25-30%

### 2-3. Magic Eden

- Solana NFT 1위
- 다중 체인 지원
- 시장 점유 약 15-20%

### 2-4. 기타

- LooksRare, X2Y2, Tensor (Solana), Element 등

## 3. 시장 회복 요인

### 3-1. RWA NFT

미술품 + 부동산 + IP 의 RWA 토큰화로 — NFT 의 *"학술적 가치 사용 사례"* 등장.

### 3-2. 게임 NFT

Axie + Big Time + Pixels 등 게임 NFT 가 — 사용자 활동 회복.

### 3-3. BTC Ordinals

비트코인 위 NFT (Ordinals) 가 — 새로운 사용 사례 + 거래량 추가.

## 4. 한국 NFT 시장

한국 NFT 진출:
- 카카오 (Klaytn) — 2021 활발, 2023 정리
- 라인 NEXT (DOSI) — 글로벌
- 11번가, SSG — 시도 후 종료
- 한국 미술품 + K-pop NFT — 글로벌 진출 시도

자세한 분석은 — #NFT3 한국 NFT 시장 참조.

## 5. 학술적 의미

NFT 가 — *"투기 거품 → 사용 사례"* 의 학술 진화 사례:
- 2021: 가치 논쟁 (거품)
- 2024-2026: 사용 사례 정착 (RWA + 게임 + IP)

이 진화가 — Cong et al. (2021) RFS framework 의 *"토큰의 사용 가치 vs 투자 가치"* 학술 분석에 부합.

<Callout type="opposing-view" title="반대 시각 · NFT 의 *근본적 가치 의문*">
NFT 비판:

첫째, ***"이미지 복사 가능성"***. 블록체인 = 소유권만 기록. 이미지 자체는 누구나 복사.

둘째, ***"투기 위주"***. 사용자 다수가 — 투기 목적 매수.

셋째, ***"한국 NFT 시장 위축"***. 한국 NFT 진출이 대부분 정리.

이 비판이 의미하는 바 — NFT 가 *"디지털 소유권 framework"* 으로는 학술 가치 있되, *"전통 자산 시장 대체"* 는 어려움.
</Callout>
