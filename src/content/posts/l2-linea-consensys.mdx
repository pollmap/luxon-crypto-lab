## 도입 — ConsenSys 라는 이름의 무게

이더리움 생태계의 인프라를 들여다보면 가장 자주 마주치는 회사가 ConsenSys 다. 2014년 Joseph Lubin 이 설립한 이 회사는 이더리움 공동 창립자가 만든 첫 대형 상업 조직이라는 상징성을 갖는다. MetaMask, Infura, Truffle, Diligence — 이름만 들어도 익숙한 도구들이 모두 이 회사 우산 아래 있다. 2024년 기준 MetaMask 누적 설치 5천만 건 이상, Infura 가 처리하는 이더리움 RPC 호출이 일 평균 수백억 건. 이더리움 네트워크에서 일어나는 거의 모든 트랜잭션은 어느 단계에서든 ConsenSys 의 인프라를 거친다고 봐도 된다.

이 회사가 2023년 7월 Linea 메인넷을 출범시켰다. 자체 Layer 2 를 만들어 직접 운영하기 시작했다는 뜻이다. 이미 zkSync Era, StarkNet, Polygon zkEVM 같은 ZK Rollup 이 자리잡은 상태였고, Optimistic Rollup 진영에는 Arbitrum 과 Optimism 이 있었다. 후발주자로 들어간 셈인데, ConsenSys 는 두 가지 무기로 차별화를 시도했다. 하나는 Type 2 zkEVM 이라는 기술적 선택. 또 하나는 MetaMask 와 Infura 라는 기존 사용자 채널을 그대로 끌어쓰는 수직 통합 전략이다.

2026년 5월 현재 Linea 의 TVL 은 약 $1B 수준. zkSync Era 와 비슷한 권역에서 경쟁하고 있고, Optimistic Rollup 진영의 Base ($14B), Arbitrum ($18B), Optimism ($7B) 과 비교하면 한 단계 작은 시장이다. 그러나 단순한 TVL 숫자만으로 이 프로토콜을 평가하면 본질을 놓치게 된다. Linea 가 노리는 자리는 "DeFi 사용자가 모이는 L2" 가 아니라 "기관과 결제망이 들어올 수 있는 L2" 쪽에 가깝다.

## 1. ConsenSys 라는 회사의 구조

### 1-1. 사업 포트폴리오

ConsenSys 의 사업은 크게 네 축으로 나뉜다. 첫째가 MetaMask. 브라우저 확장 프로그램과 모바일 앱으로 제공되는 비수탁형 지갑이다. 2024년 MetaMask Card, MetaMask Snaps 같은 부가 기능을 통해 단순 지갑에서 결제 · 인증 플랫폼으로 확장 중이다. 둘째가 Infura. 이더리움 노드를 직접 운영하지 않는 개발자에게 RPC 엔드포인트를 제공한다. 무료 티어부터 엔터프라이즈 플랜까지 있고, AWS 와 Cloudflare 가 그렇듯이 사실상 이더리움 RPC 시장의 표준 인프라가 됐다. 셋째가 Truffle, Hardhat 통합 도구로 이전된 개발자 툴체인. 넷째가 Linea 자체.

이 구조에서 Linea 의 의미는 명확하다. 기존 사업의 사용자 베이스를 유료 트랜잭션이 발생하는 자체 체인으로 옮길 수 있는 채널이다. MetaMask 사용자가 Linea 에서 트랜잭션을 발생시키면, Sequencer 를 운영하는 ConsenSys 가 가스비 일부를 수익으로 가져간다. Infura 가 처리하는 RPC 호출 중 일부가 Linea 호출로 전환되면 그것도 ConsenSys 매출이 된다. 즉 Linea 는 ConsenSys 의 사용자 베이스를 monetize 하는 도구이기도 하다.

### 1-2. Linea 의 거버넌스 구조

Linea 는 2026년 5월 현재까지 자체 토큰을 발행하지 않았다. Sequencer 는 ConsenSys 가 단독 운영한다. 거버넌스 결정도 사실상 ConsenSys 내부에서 이루어진다. 이 구조는 Base 와 매우 비슷하다. Base 의 Sequencer 를 Coinbase 가 단독 운영하고, OP Stack 의 거버넌스는 Optimism Collective 와 분리돼 있다. Linea 도 같은 패턴이다. "분산 L2" 를 표방하지 않는다. 대신 "신뢰할 수 있는 단일 운영자" 모델을 명시한다.

이 선택은 ConsenSys 의 기관 영업 전략과 일치한다. 은행과 결제 회사가 토큰화 인프라를 검토할 때 가장 큰 거부 요소는 "운영 책임자가 누구인지 불분명한 분산 네트워크" 였다. ConsenSys 가 Sequencer 를 직접 운영하고 SLA 를 제공하면 이 거부감이 사라진다. 대신 분산성 점수는 떨어진다. L2Beat 가 Linea 를 Stage 0 으로 분류하는 이유다. Stage 0 은 운영자가 자체 의지로 사용자 자금을 동결하거나 압수할 수 있는 권한을 갖는 L2 를 의미한다.

## 2. Type 2 zkEVM 의 기술적 의미

### 2-1. Vitalik 의 zkEVM 분류

zkEVM 의 종류를 구분하는 표준 framework 은 Vitalik Buterin 이 2022년 7월 발표한 분류다. Type 1 부터 Type 4 까지 네 단계로 나뉜다. Type 1 은 이더리움 자체와 완전히 동일한 EVM 을 ZK 증명으로 검증한다. Type 2 는 EVM 동등성은 유지하되 일부 내부 구현을 ZK 증명에 유리하도록 변경한다. Type 3 은 일부 opcode 를 변경하거나 제거한다. Type 4 는 Solidity 소스 코드를 자체 ZK 친화적 IR 로 컴파일한다.

Linea 는 Type 2 를 채택했다. EVM bytecode 를 그대로 실행할 수 있고, 기존 이더리움 메인넷의 스마트 컨트랙트를 거의 수정 없이 배포할 수 있다. 단, 일부 precompile 과 storage 구조가 ZK 증명 효율을 위해 변경됐다. Polygon zkEVM 도 Type 2 에 가깝고, Scroll 은 Type 2.5 에 가깝다. zkSync Era 는 Type 4 다. 자체 VM 과 자체 컴파일러를 사용하며, Solidity 코드를 zkSync 만의 IR 로 변환한다.

### 2-2. Type 별 trade-off

Type 1 ↔ Type 4 의 trade-off 는 명확하다. Type 1 에 가까울수록 EVM 호환성이 높고 개발자가 코드를 수정할 필요가 없다. 그러나 ZK 증명을 생성하는 데 시간이 오래 걸린다. Type 4 에 가까울수록 증명 생성이 빠르고 효율적이지만, 개발자가 자체 도구체인에 적응해야 한다. zkSync Era 의 증명 생성 속도가 Linea 보다 빠른 것은 이 차이 때문이다. 반대로 이더리움 메인넷에서 검증된 컨트랙트를 그대로 가져올 수 있는 능력은 Linea 가 우위다.

이 trade-off 는 "어떤 사용자를 노리는가" 에 따라 합리적 선택이 갈린다. 빠른 트랜잭션과 자체 토큰 인센티브로 일반 사용자를 모으려면 Type 4 가 유리할 수 있다. 반대로 기존 DeFi 프로토콜과 기관 시스템을 끌어와야 한다면 Type 2 가 유리하다. ConsenSys 는 후자를 선택했다. Aave, Curve, Uniswap, 1inch 같은 기존 메이저 프로토콜이 Linea 에 배포된 것은 이 호환성 덕분이다.

### 2-3. ZK 증명 생성 인프라

Linea 의 증명 생성은 PLONK 기반 회로와 자체 개발한 lattice-based 증명 시스템을 결합한다. 2024년 도입된 lattice 증명은 양자 내성을 일부 갖춘다는 점에서 학술적으로 흥미롭다. 그러나 실제 Linea 의 증명 생성 시간은 zkSync Era, StarkNet 보다 길다. 트랜잭션 확정까지 약 12~24시간이 걸린다. 사용자 입장에서 자금을 L1 으로 출금할 때 이 대기 시간을 거쳐야 한다. Optimistic Rollup 의 7일 challenge period 보다는 짧지만, "ZK Rollup 은 즉시 출금" 이라는 통념과 다르다.

## 3. MetaMask 통합과 사용자 진입 경로

### 3-1. 자동 RPC 등록

Linea 의 가장 강력한 사용자 채널은 MetaMask 다. 2023년 7월 메인넷 출범과 동시에 MetaMask 의 네트워크 추가 메뉴에 Linea 가 기본 옵션으로 등장했다. 다른 L2 는 사용자가 RPC URL, Chain ID, Block Explorer 를 직접 입력해야 했다. Arbitrum 도 한참 동안 그랬다. Linea 는 MetaMask 가 ConsenSys 자회사 제품이라는 이유로 한 번의 클릭으로 네트워크가 추가된다. 사용자 마찰이 압도적으로 낮다.

이 효과를 정량적으로 보면 흥미롭다. L2Beat 데이터 기준 Linea 의 일 활성 주소 수는 약 30만~50만 개 수준에서 등락한다. zkSync Era 와 비슷하지만, Linea 의 사용자 확보 비용은 zkSync Era 보다 훨씬 낮다고 추정된다. zkSync Era 는 토큰 에어드롭 인센티브로 사용자를 끌어왔다. Linea 는 토큰 없이 MetaMask 통합만으로 비슷한 활성도를 달성했다. 이 차이가 ConsenSys 가 강조하는 "기존 인프라 자산의 가치" 를 보여준다.

### 3-2. MetaMask Snaps 와의 연계

2024년 MetaMask 가 Snaps 라는 플러그인 시스템을 출시했다. 외부 개발자가 MetaMask 에 기능을 확장할 수 있는 SDK 다. Linea 팀은 자체 Snap 을 통해 Linea 트랜잭션 시뮬레이션, NFT 표시, 익명 거래 옵션을 MetaMask 에 직접 통합했다. 사용자는 MetaMask 안에서 Linea 의 모든 기능을 쓸 수 있다. 다른 L2 는 별도 dApp 을 열거나 자체 지갑을 설치해야 비슷한 경험을 얻는다.

### 3-3. Linea Voyage 캠페인

2023~2024년 진행된 Linea Voyage 는 사용자 활동에 기반한 포인트 시스템이었다. 토큰 에어드롭은 명시되지 않았지만, 시장은 이를 미래 토큰 분배의 사전 작업으로 읽었다. 약 4개월간 누적 사용자 590만 명, 트랜잭션 1.5억 건이 발생했다. 이 캠페인이 Linea 의 사용자 베이스 중 큰 비중을 만들었고, 동시에 "토큰 발행을 전제로 한 사용자 참여" 라는 ConsenSys 의 미공개 옵션을 시장에 시사했다.

## 4. 기관 결제망 통합 시도

### 4-1. SWIFT, MasterCard, JP Morgan 협력

ConsenSys 가 Linea 를 기관 인프라로 포지셔닝하면서 가장 자주 언급되는 협력 사례는 SWIFT 와의 토큰화 결제 PoC 다. 2024년 발표된 SWIFT-Chainlink-ConsenSys PoC 에서 Linea 가 결제 정산 레이어 후보 중 하나로 시연됐다. MasterCard 도 Linea 위에서 디지털 자산 카드 결제 PoC 를 진행했다. JP Morgan Onyx 의 토큰화 자산 시스템도 Linea 와 호환성 테스트를 거쳤다고 보고됐다.

이 협력의 실체를 정확히 평가하려면 PoC 와 production 의 차이를 구분해야 한다. 위 사례는 모두 PoC 단계이고, 실제 결제 트래픽이 Linea 에서 처리되는 것은 아니다. 그러나 PoC 단계의 협력만으로도 의미가 있다. 기관이 토큰화 인프라를 검토할 때 가장 먼저 고려하는 후보군에 Linea 가 포함된다는 신호이기 때문이다. 같은 시점 다른 L2 들은 PoC 협력 사례 자체가 거의 보고되지 않았다.

### 4-2. MiCA 와 유럽 기관 진출

2024년 12월 EU MiCA (Markets in Crypto-Assets Regulation) 가 본격 발효되면서 유럽 시장의 가상자산 인프라 요건이 명확해졌다. 결제 토큰 (E-Money Token), 자산 참조 토큰 (Asset-Referenced Token), 그 외 가상자산이 각각 별도 라이선스 체계를 갖추게 됐다. 토큰 발행자는 백서 등록 의무, 자본금 요건, 준비금 보관 요건을 충족해야 한다. 대형 발행자는 추가 자본금 요건이 부과된다.

이 환경에서 ConsenSys 의 유럽 본부 (스위스 Zug) 와 Linea 의 결합이 의미를 갖는다. 유럽 은행이 토큰화 자산을 발행할 때 인프라 운영자가 명확하고, 운영자가 EU 법인이며, KYC 와 AML 절차가 결합 가능한 L2 를 선택해야 한다. Linea 는 Sequencer 를 ConsenSys 가 단독 운영하기 때문에 이 조건을 모두 충족한다. 분산성을 강조하는 Optimism, Arbitrum, zkSync Era 보다 Linea 가 유럽 기관 영업에서 유리한 이유다.

### 4-3. 한국 시장과의 거리

한국 STO 인프라가 Linea 위에서 구축될 가능성은 현재 시점에서 낮다. 한국 STO 시장은 자본시장법 개정 트랙 위에서 움직이고 있고, 발행 인프라의 후보로는 KRX 의 분산원장, KSD (한국예탁결제원) 의 토큰 증권 인프라, 그리고 일부 사설 컨소시엄 체인이 거론된다. 글로벌 퍼블릭 L2 가 직접 한국 STO 발행 레이어가 될 가능성은 단기적으로 제한적이다. 그러나 글로벌 자산을 한국에 분산 판매하거나, 한국 자산을 글로벌에 분산 판매할 때 cross-chain 게이트웨이로 Linea 가 후보가 될 수는 있다. 이 시나리오는 KCMI 와 자본시장연구원 보고서에서 일부 다뤄진다.

## 5. Linea 토큰 부재 모델의 분석

### 5-1. 현재 상태

Linea 는 2026년 5월 시점까지 자체 토큰을 발행하지 않았다. 거버넌스 토큰도, 가스 토큰도 없다. 가스비는 ETH 로 지급된다. Sequencer 가 받는 가스비 수익은 ConsenSys 본사 수익으로 들어간다. 사용자 보상 프로그램 (Linea Voyage) 도 포인트 형태로만 운영된다.

이 구조의 가장 가까운 비교 대상은 Base 다. Base 도 자체 토큰 없이 ETH 가스, Coinbase 수익 흡수 구조다. Optimism 과 Arbitrum 의 OP, ARB 토큰 모델과 정반대다. OP 와 ARB 는 거버넌스 토큰이고, 일부는 Sequencer 수익을 토큰 보유자에게 분배하는 메커니즘 도입을 검토 중이다. Linea 와 Base 는 그 메커니즘이 아예 존재하지 않는다.

### 5-2. 토큰 미발행의 trade-off

토큰 미발행이 주는 장점은 두 가지다. 첫째, 미국 SEC 의 증권성 판단에서 자유롭다. Howey Test 에서 가장 핵심적인 요소는 "타인의 노력으로 발생하는 수익에 대한 합리적 기대" 인데, 토큰이 없으면 이 판단 자체가 발생하지 않는다. 둘째, 기관 영업에서 단순함을 제공한다. 기관 사용자는 토큰 가격 변동성과 거버넌스 정치에 노출되기를 꺼린다.

단점도 명확하다. 사용자 인센티브와 개발자 인센티브를 토큰으로 분배할 수 없다. Arbitrum 의 STIP, Optimism 의 RetroPGF 같은 대규모 생태계 인센티브 프로그램이 Linea 에는 없다. 사용자 입장에서 Linea 를 선택할 financial 인센티브가 약하다. 또한 토큰 가격이라는 vendible asset 이 없어서 시장의 관심을 측정하기도 어렵다.

### 5-3. 미래 토큰 발행 가능성

ConsenSys 는 공식적으로 Linea 토큰 발행을 부정하지도 확정하지도 않았다. 시장은 Linea Voyage 캠페인을 토큰 에어드롭의 사전 작업으로 해석했고, 2024~2025년 사이 토큰 발행 가능성이 자주 거론됐다. 만약 발행한다면 그 분배 구조가 ConsenSys 의 기관 영업 전략과 충돌하지 않아야 한다. 한 가지 가능한 시나리오는 거버넌스 토큰만 발행하고 가스 토큰은 ETH 로 유지하는 것. Optimism 의 OP 와 비슷한 구조다.

## 6. 시장 위치와 경쟁 구도

### 6-1. ZK Rollup 진영 내부 위치

ZK Rollup 진영은 2026년 5월 기준 zkSync Era, StarkNet, Linea, Polygon zkEVM, Scroll, Taiko 정도가 주요 플레이어다. TVL 기준으로 zkSync Era ($800M), Linea ($1B), StarkNet ($600M), Scroll ($400M), Polygon zkEVM ($150M), Taiko ($100M) 순이다. Linea 는 ZK Rollup 중에서 1~2위를 다투는 위치에 있다. 1년 전 (2025년 5월) 보다 TVL 이 약 3배 증가했다. 같은 기간 zkSync Era 의 TVL 은 토큰 발행 후 큰 변동 없이 정체했다.

이 차이는 토큰 인센티브의 효과를 다시 보게 만든다. zkSync Era 는 2024년 6월 ZK 토큰을 발행했고, 토큰 가격 하락과 함께 사용자 활동이 둔화됐다. Linea 는 토큰 없이 점진적으로 TVL 을 늘렸다. 두 패턴 중 어느 쪽이 더 지속 가능한지는 아직 결론이 나지 않았다.

### 6-2. Optimistic Rollup 과의 경쟁

전체 L2 시장에서 ZK Rollup 과 Optimistic Rollup 의 비중은 여전히 Optimistic 진영이 크다. Arbitrum + Optimism + Base 의 TVL 합이 약 $39B 로 ZK Rollup 진영 전체 ($3B) 의 10배가 넘는다. ZK Rollup 의 기술적 우위는 여러 차례 학술적으로 입증됐지만, 시장 점유는 따라가지 못하고 있다. 이유는 두 가지로 분석된다. Optimistic Rollup 이 먼저 메인넷을 출시한 first-mover 효과, 그리고 EVM 호환성에서 초기에는 Optimistic 이 우위였던 영향.

ZK Rollup 진영이 Type 2 ~ Type 1 으로 진화하면서 호환성 격차는 좁혀졌다. 그러나 first-mover 효과는 여전하다. Linea 가 이 격차를 따라잡으려면 ConsenSys 의 채널 우위만으로는 부족하고, 기관 결제망 진출이 실제 production 단계로 이어져야 한다. 그것이 가시화되는 시점이 Linea 의 다음 변곡점이 될 가능성이 크다.

## 7. 위험 요인

### 7-1. ConsenSys 단독 의존

Linea 의 가장 명확한 위험은 ConsenSys 단독 의존이다. Sequencer, RPC, 지갑, 개발 도구가 모두 한 회사 안에서 운영된다. ConsenSys 가 재정 위기에 빠지거나, SEC 규제로 사업 일부가 동결되거나, 기업 매각이 일어나면 Linea 의 운영 연속성이 흔들린다. 2023년 ConsenSys 가 SEC 로부터 MetaMask 스왑 기능과 Staking 기능에 대한 Wells Notice 를 받은 사례가 있었다. 2024년 SEC 가 이 조사를 종결했지만, 미국 규제 리스크는 여전히 잔존한다.

### 7-2. 토큰 부재의 장기 비용

토큰이 없는 L2 는 단기적으로 깔끔하지만 장기적으로 생태계 인센티브 부재가 누적된다. Arbitrum 과 Optimism 이 STIP, RetroPGF 같은 대형 인센티브 프로그램으로 빌더를 끌어모으는 동안, Linea 는 ConsenSys 본사 자금에서 보조금을 직접 지원해야 한다. 이 보조금이 끊어지면 빌더가 떠날 가능성이 있다.

### 7-3. 기관 채택의 PoC 함정

PoC 협력이 production 으로 이어지지 않는 경우가 가상자산 산업에서 흔하다. 2018~2020년 IBM Hyperledger 컨소시엄, Ripple 의 은행 협력, R3 Corda 의 ISDA 협력 모두 PoC 단계에서 화제가 됐지만 실제 결제 트래픽으로 이어진 비중은 작았다. Linea 의 SWIFT, MasterCard, JP Morgan 협력도 같은 운명을 겪을 가능성을 배제할 수 없다.

Linea 의 강점은 명확하지만, 비판적 관점도 만만치 않다.

첫째, 분산성 부재. Sequencer · RPC · 지갑이 모두 ConsenSys. L2Beat 기준 Stage 0. "이더리움의 보안을 상속받는다" 는 L2 의 기본 명제가 무색해진다는 비판.

둘째, MetaMask 통합 효과의 일회성. MetaMask 가 Linea 를 기본 등록한 효과는 출시 초기에만 작용한다. 사용자가 한 번 등록한 후의 retention 은 다른 L2 와 같은 조건에서 경쟁한다.

셋째, 기관 PoC 의 실체. SWIFT, MasterCard, JP Morgan 협력이 모두 PoC 단계. 실제 결제 트래픽이 Linea 에서 발생한 사례는 아직 없음.

넷째, 토큰 부재 모델의 한계. 빌더 인센티브가 ConsenSys 본사 자금에서 나오는 보조금에 의존. 자금 흐름이 끊어지면 생태계 활력 저하.

다섯째, ZK Rollup 시장 자체의 정체. Optimistic Rollup 이 시장 점유 90% 이상 차지하는 구도가 1년 가까이 유지. ZK Rollup 의 기술적 우위가 시장 우위로 전환되지 않는 패턴.

이 다섯 가지가 의미하는 바는 분명하다. Linea 가 "기관 친화 ZK Rollup" 이라는 포지션 자체는 가치 있지만, 이 포지션이 시장 점유로 전환되려면 PoC 가 production 으로 이어지는 다음 단계 검증이 필요하다.

## 마무리

Linea 가 보여주는 것은 L2 가 단순한 확장 솔루션이 아니라 사업 채널이라는 사실이다. ConsenSys 는 MetaMask 와 Infura 를 통해 이미 이더리움 인프라의 절반을 장악했고, Linea 는 그 채널의 monetization layer 다. 토큰 없이도 L2 가 작동할 수 있다는 것을 Base 와 함께 증명했고, Type 2 zkEVM 으로 EVM 호환성을 유지하면서 ZK 증명의 보안을 가져왔다. 동시에 Sequencer 를 단독 운영하면서 분산성 점수는 포기했다. 이 trade-off 는 일관된 사업 전략의 결과지 우연이 아니다.

다만 이 전략의 성공 여부는 결국 기관 결제망 진출이 실제 production 단계로 이어지는가에 달려 있다. SWIFT 와 MasterCard 의 PoC 가 매출을 만드는 production 시스템으로 전환되면 Linea 는 다른 L2 와 다른 카테고리에 자리잡는다. 그렇지 않으면 단순히 "MetaMask 가 기본 등록한 또 하나의 L2" 로 남는다. 다음 1~2년이 그 갈림길이다. 다음 편 (#L6) 에서는 Scroll 과 Taiko 의 커뮤니티 ZK Rollup 두 모델을 다룬다.
