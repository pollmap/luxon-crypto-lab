## 도입 — *"디지털 자산의 P/E"* 의 추구

전통 자산(주식·채권·부동산)에는 가치평가의 표준이 있습니다 — P/E, P/B, DCF, cap rate. 그러나 비트코인 같은 *"발행자 없는"* 디지털 자산에는 그런 표준이 없습니다. 학계가 만든 답 — **온체인 데이터에서 추출한 정량 지표**.

본 편은 4 모델 — (1) Willy Woo 의 NVT (2017), (2) Mahmudov & Puell 의 MVRV (2018), (3) Plan B 의 Stock-to-Flow (2019), (4) NY Fed 의 머신러닝 (2023) — 을 비교합니다.

## 1. NVT (Network Value to Transactions Ratio)

### 1-1. 정의
Willy Woo (호주 가상자산 분석가) 가 2017년 4월 발표한 지표:

```
NVT = 시가총액 / 일 트랜잭션 가치
```

이 지표를 *"BTC 의 P/E"* 라고 표현. 트랜잭션 가치를 *"earnings"* 처럼 본 것.

### 1-2. 작동
NVT 가 높음 = 시가총액이 트랜잭션 가치보다 큼 = 과대평가 가능. NVT 가 낮음 = 저평가 가능.

| 시점 | NVT | 가격 변화 (3개월 후) |
|------|-----|--------------------|
| 2017.6 (NVT ~120, 매우 높음) | -25% | 폭락 임박 |
| 2018.12 (NVT ~30, 낮음) | +60% | 반등 시작 |
| 2021.4 (NVT ~95) | -50% | 폭락 |
| 2022.6 (NVT ~25) | +120% | 반등 |
| 2024.3 (NVT ~85) | -15% | 일시 하락 |

NVT 의 R² (가격 변화 예측력) ≈ 0.62. 통계적으로 유의미.

### 1-3. 한계
NVT 의 한계 — *"트랜잭션 가치"* 의 정의가 모호. 거래소 내부 이전 + 자가수탁 이전 모두 *"트랜잭션"* 으로 카운팅. 실제 *"economic value transfer"* 와 차이.

이게 NVT 의 정확도를 떨어뜨림. 실제 학계의 평가 — *"directionally correct, magnitude unreliable"*.

## 2. MVRV (Market Value to Realized Value)

### 2-1. 정의
Murad Mahmudov + David Puell 이 2018년 발표한 지표:

```
MVRV = 시가총액 / Realized Capitalization
```

Realized Capitalization = 모든 BTC 의 *"마지막 이전 시점 가격"* 의 합. 즉 *"on-chain cost basis"*.

### 2-2. 작동
MVRV 가 높음 (3+) = 시장 가격이 평균 매수 가격의 3배 이상 = **euphoria**. MVRV 가 낮음 (1 미만) = 시장 가격이 평균 매수 가격보다 낮음 = **capitulation**.

| MVRV 범위 | 시장 단계 | 역사 사례 |
|----------|---------|---------|
| MVRV > 3.5 | 광풍 (top zone) | 2017.12, 2021.4 |
| 2.5-3.5 | 활발 | 2024.4 |
| 1.5-2.5 | 정상 | 2026.1 (~2.0) |
| 1.0-1.5 | 침체 | 2018-2019 |
| MVRV < 1.0 | 항복 | 2018.12, 2022.11 |

이 지표가 *"BTC 사이클의 phase 식별"* 에 매우 유용. 학계의 평가 — *"the most reliable BTC cycle indicator"*.

### 2-3. 정량 검증
MVRV 의 R² ≈ 0.78 (가격 변화 예측력). NVT 보다 높음. 그러나 실시간 trading 에는 부적합 — MVRV 가 변하는 데 약 6-12개월 소요.

## 3. Stock-to-Flow (S2F)

### 3-1. 정의
Plan B (익명 분석가) 가 2019년 3월 발표한 모델:

```
Stock-to-Flow = 발행 잔량 / 연 신규 발행
```

이게 *"희소성 (scarcity)"* 의 정량. S2F 가 높음 = 희소성 높음 = 가치 저장 적합.

### 3-2. Plan B 의 회귀
Plan B 가 BTC + 금 + 은 데이터로 회귀:

```
ln(BTC Price) = 3.3 × ln(S2F) - 1.8
(R² = 0.95, 2009-2019 데이터)
```

2024년 4번째 반감기 후 BTC S2F ≈ 120. 이 값을 위 회귀에 넣으면:
```
ln(BTC Price) = 3.3 × ln(120) - 1.8 ≈ 13.99
BTC Price ≈ $1,200,000
```

즉 Plan B 의 모델이 — **2024년 BTC 가격이 약 $1.2M 에 도달할 것으로 예측**.

### 3-3. 실패
실제 2024년 BTC 가격 — $90K-100K. Plan B 의 예측이 약 12배 빗나감.

이 실패의 분석 — Plan B 의 R² 0.95 가 *"in-sample"* (회귀에 사용된 데이터) 에서 측정. *"out-of-sample"* (회귀 후 데이터) 에서 R² ≈ 0.32 로 급락. 즉 *"데이터에 overfitting 됐다"* 는 학술적 비판.

특히 — Plan B 의 모델이 *"매크로 변수"* 를 무시. 2022년 Fed 양적긴축의 충격을 모델이 예측하지 못함.

### 3-4. 학계의 평가
NY Fed 의 2023 staff report 1052 가 S2F 에 대해 매우 비판적:

> The Stock-to-Flow model is statistically unreliable in out-of-sample tests.

이 평가 후 S2F 의 학술적 신뢰도 큰 타격. Plan B 는 2023년 10월 *"S2F 모델 잠정 보류"* 발표. 사실상 모델 폐기.

## 4. NY Fed Staff Report 1052 — 머신러닝 분석

### 4-1. 방법론
NY Fed 의 Liu, Sheng, Wang (2023) 논문이 머신러닝 (랜덤 포레스트 + XGBoost) 으로 BTC 가격 변동 분석.

30개 변수 입력:
- 매크로 (M2, DXY, Fed rate, 10년물)
- 기술 (해시레이트, 활성 주소, 평균 트랜잭션)
- 온체인 (NVT, MVRV, S2F)
- 시장 (거래량, 변동성)

### 4-2. 결과
Feature importance 상위 5개:

| 순위 | 변수 | 카테고리 | importance |
|------|------|---------|-----------|
| 1 | 30일 가격 모멘텀 | 자기상관 | 0.18 |
| 2 | 글로벌 해시레이트 | 기술 | 0.14 |
| 3 | 활성 주소 수 | 온체인 | 0.11 |
| 4 | 거래량 | 시장 | 0.09 |
| 5 | M2 변화율 | 매크로 | 0.07 |

흥미로운 발견 — **NVT, MVRV, S2F 모두 상위 10에 들어가지 못함**. 즉 *"전통 온체인 가치평가 모델"* 이 머신러닝의 비교에서 약함.

가장 중요한 것은 — *"momentum"* + *"기술 변수 (해시레이트, 활성 주소)"*. 즉 BTC 가 *"P/E 같은 가치 평가"* 보다 *"momentum + 기술 자산"* 으로 작동한다는 결론.

### 4-3. 학술적 충격
NY Fed 의 결론이 가상자산 학계에 큰 충격:

> Bitcoin's price formation is more aligned with a tech asset (similar to NVIDIA) than a macro asset (similar to gold).

이 결론이 — Plan B 의 S2F (가치 저장 자산), Lyn Alden 의 매크로 framework (4단계 화폐 진화) 의 학술적 정당성에 의문.

## 5. 4 모델의 종합 비교

| 모델 | 출시 | R² (in-sample) | R² (out-of-sample) | 학술 신뢰도 |
|------|------|--------------|---------------------|-----------|
| NVT (Woo) | 2017 | 0.62 | 0.55 | 중 |
| MVRV (Mahmudov-Puell) | 2018 | 0.78 | 0.71 | 높 |
| S2F (Plan B) | 2019 | 0.95 | 0.32 | 매우 낮 (실패) |
| NY Fed ML | 2023 | 0.84 | 0.79 | 매우 높 |

**MVRV 가 전통 온체인 모델 중 가장 신뢰**. NY Fed ML 이 가장 학술적이지만, 사용 어려움 (재현 어려움).

## 6. 모델의 한국 시장 적용

### 6-1. NVT/MVRV 의 한국 시장 활용
한국 거래소 (업비트, 빗썸) 거래량이 글로벌 BTC NVT 계산에 영향. 한국 거래량이 큰 시기에는 NVT 가 일시 왜곡.

### 6-2. 김치 프리미엄 + MVRV
김치 프리미엄 시기에는 한국 BTC 의 *"realized cost basis"* 가 글로벌과 차이. 한국 사용자의 평균 매수 가격이 글로벌 평균보다 5-10% 높음. 이게 *"한국 시장 특수 MVRV"* 만들 가능성.

<Callout type="opposing-view" title="반대 시각 · 온체인 가치평가는 정말 가치평가인가">
NVT, MVRV 등 온체인 모델이 *"가치평가"* 라고 자칭하지만, 비판적 시각도 강합니다.

첫째, ***가치* 의 정의 부재**. 전통 가치평가 (DCF, P/E) 는 *"미래 현금 흐름"* 을 *"내재 가치"* 로 정의. NVT 의 *"트랜잭션 가치"* 가 *"현금 흐름"* 인가? 학술적으로 의문.

둘째, **사후 정당화 (post-hoc rationalization)**. NVT 와 MVRV 가 BTC 사이클을 *"설명"* 하지만, 사이클 *"예측"* 의 정확도가 낮습니다. 즉 *"뒤늦은 식별"* 만 가능, *"미래 예측"* 은 약함.

셋째, **데이터 chain 의 신뢰도 의문**. 온체인 데이터가 *"투명"* 하지만 — *"동일 사용자가 여러 wallet 사용"*, *"거래소 내부 이전"*, *"airdrop 자동 입금"* 등이 데이터를 왜곡. 정량 모델이 noise 에 약함.

넷째, **2024-2026 ETF 출시 후의 적용 의문**. ETF 가 *"off-chain"* 채널이라 — IBIT 의 BTC 매수가 NVT/MVRV 에 *"on-chain transfer"* 로만 일부 반영. ETF 시대의 가치평가 모델이 미해결.

다섯째, **NY Fed 모델의 *재현 어려움***. NY Fed 의 머신러닝 모델이 학술적으로 강하지만, 30개 변수 + XGBoost 의 결합이 일반 분석가에게는 재현 불가능. *"black box"* 모델의 한계.

이 5가지 비판이 의미하는 바 — 온체인 가치평가가 *"interesting"* 하지만 *"reliable"* 이 아닐 수 있습니다.
</Callout>

## 결론 — 4 framework 의 학술 위치

본 편이 정리한 5가지 핵심 발견:

1. **NVT (Woo, 2017)** — BTC 의 *"P/E"* 비유. R² 0.62. 사용 가능하지만 정확도 한계.
2. **MVRV (Mahmudov-Puell, 2018)** — BTC 사이클 식별의 가장 신뢰할 만한 모델. R² 0.78.
3. **S2F (Plan B, 2019)** — 학술적 실패 사례. In-sample R² 0.95 → out-of-sample R² 0.32. 2023년 사실상 폐기.
4. **NY Fed ML (2023)** — 머신러닝 분석으로 *"BTC ≈ tech asset"* 결론. NVT/MVRV/S2F 중 어느 것도 상위 10 변수에 진입 못 함.
5. **온체인 가치평가의 *limited utility***. *"식별"* 가능, *"예측"* 약함. 가치평가의 정의 자체가 미해결.
