## 도입 — "sentiment 의 정량화"

가상자산 시장의 가장 "emotional" 측면 — 사용자 sentiment. "공포" 와 "탐욕" 의 사이클이 가격을 끌어가는 패턴이 학술적으로 검증. "buy when others are fearful, sell when others are greedy" — Warren Buffett 의 명언이 가상자산에서도 작동.

Alternative.me 가 2018년 출시한 "Crypto Fear & Greed Index" 가 이를 정량화. 글로벌 가상자산 sentiment 의 표준.

## 1. Fear & Greed Index 의 5 Component

### 1-1. 합산 방법
Index = 5 component 가중 평균:
1. **변동성 (25%)** — 30일/90일 평균 대비 현재 변동성
2. **거래량 (25%)** — 30일/90일 평균 대비 현재 거래량
3. **소셜 미디어 (15%)** — Twitter + Reddit hashtag 빈도
4. **도미넌스 (10%)** — BTC dominance 변화
5. **Google Trends (10%)** — "Bitcoin" 검색 빈도
6. **설문 (15%)** — 사용자 직접 설문 (작은 표본)

### 1-2. 점수 0-100
| 점수 | 단계 |
|------|------|
| 0-24 | Extreme Fear |
| 25-49 | Fear |
| 50 | Neutral |
| 51-74 | Greed |
| 75-100 | Extreme Greed |

### 1-3. 역사 사례
| 시점 | Index | 단계 | 결과 |
|------|-------|------|------|
| 2017.12 | 95 | Extreme Greed | -85% 폭락 |
| 2018.12 | 8 | Extreme Fear | +600% 반등 |
| 2021.4 | 92 | Extreme Greed | -50% 조정 |
| 2022.6 | 6 | Extreme Fear | +120% 반등 |
| 2024.3 | 88 | Extreme Greed | -20% 조정 |
| 2026.1 | 65 | Greed | 안정 |

**Extreme Greed 후 폭락, Extreme Fear 후 반등** 의 패턴이 4 사이클 검증.

## 2. Google Trends — "검색 = 채택"

### 2-1. "Bitcoin" 검색 빈도
| 시점 | Google Trends 점수 (0-100) |
|------|--------------------------|
| 2017.12 | 100 (사상 최고) |
| 2021.5 | 73 |
| 2024.3 | 68 |
| 2025.10 | 35 |
| 2026.1 | 28 |

Google Trends 가 "가격 보다 사이클을 약간 빨리 capture" 의 lead indicator 인지 학계 논쟁.

### 2-2. 한국 사용자
"비트코인" 한국어 검색 빈도가 글로벌 "Bitcoin" 검색과 약 0.85 상관. 한국 사용자가 "가격 가속 시 검색 가속" 의 동조.

### 2-3. "Buy bitcoin" vs "Sell bitcoin"
"Buy bitcoin" 검색 vs "Sell bitcoin" 검색 비율도 sentiment 신호. 평소 "Buy" 가 더 높지만, "Sell" 가속 시 항복 신호.

## 3. Twitter Sentiment

### 3-1. Santiment 의 "Crypto Twitter Sentiment"
Santiment 가 BTC 관련 Twitter 글의 sentiment 분석 (NLP 기반). 0-100 점수.

### 3-2. 영향력 있는 인물의 sentiment
- Saylor (Strategy CEO) — 영구 강세
- Cathie Wood (ARK) — 강세 (BTC $1.5M 가설)
- Vitalik (ETH) — 균형
- 익명 인플루언서 — 변동

### 3-3. "FOMO" 신호
Twitter 의 "to the moon" + "diamond hands" hashtag 빈도 가속 = FOMO 가속. 단기 정점 임박 신호.

## 4. 한국 시장 적용

### 4-1. 한국 retail 의 빠른 sentiment 변화
한국 사용자의 sentiment 가 글로벌 보다 빠르게 변동. 한국 가상자산 보호원의 분기 설문 — 한국 사용자의 "sentiment volatility" 가 미국 보다 약 1.4배.

### 4-2. "네이버 검색" 보조
글로벌 Google Trends 외에 한국에서는 "네이버 검색 트렌드" 가 보조 지표. 비트코인 검색이 한국에서 가속 시 김치 프리미엄 가속과 동조.

### 4-3. 한국형 Fear & Greed
한국 사용자만의 unique sentiment — 글로벌 + 김치 프리미엄 + 한국 정책 + 한국 미디어 의 결합. 한국형 인덱스가 학계에서 시도되지만 표준화 X.

<Callout type="opposing-view" title="반대 시각 · Sentiment 신호의 한계">
Fear & Greed Index 가 4 사이클 검증됐지만, 비판적 시각도 있습니다.

첫째, **lagging indicator** 한계. Sentiment 가 "가격 변화 후" 변화. 즉 "가격이 떨어진 후 사용자가 fear". Lead indicator 가 아님.

둘째, **5 component 가중치의 임의성**. 25/25/15/10/10/15 의 가중치가 "역사 fit" 이지 학술적 정당성 약함.

셋째, **소셜 미디어 manipulation**. Twitter/Reddit 의 hashtag 가 일부 trader 의 "의도적 마케팅" 으로 조작. "진정한 sentiment" 와 차이.

넷째, **Google Trends 의 "causation vs correlation"**. 검색 가속이 "가격 가속 결과" 인지 "가격 가속 원인" 인지 명확하지 않음.

다섯째, **한국 unique 패턴이 standard 화 어려움**. 한국 사용자의 빠른 sentiment 가 글로벌 인덱스로 capture 어려움.

이 5가지 비판이 의미하는 바 — Sentiment 가 "식별 도구" 이지 "trading signal" 의 single source 가 아닙니다.
</Callout>

## 결론 — 4가지 핵심 발견

1. **Fear & Greed Index 5 component**. 변동성 + 거래량 + 소셜 + 도미넌스 + Google + 설문.
2. **Extreme Greed (75+) 후 폭락, Extreme Fear (25-) 후 반등** — 4 사이클 검증.
3. **Google Trends + Twitter sentiment 가 보조 지표**.
4. **한국 sentiment 가 글로벌 대비 1.4배 변동성**. 빠른 변화.
