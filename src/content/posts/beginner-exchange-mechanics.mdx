거래소가 어떻게 작동하는지 — *"매수 버튼"* 을 눌렀을 때 무엇이 일어나는지를 5분에 이해. CEX (중앙) vs DEX (분산) 의 차이.

## 1. 거래소의 두 종류

### 1-1. CEX (Centralized Exchange)

중앙집중형 거래소. 회사가 운영.
- 업비트, 빗썸 (한국)
- Binance, Coinbase, Kraken (글로벌)
- 사용자 자산을 거래소가 보관

### 1-2. DEX (Decentralized Exchange)

분산 거래소. 스마트 컨트랙트가 운영.
- Uniswap, Curve (이더리움)
- Aerodrome (Base)
- 사용자가 자기 자산 직접 보관

## 2. CEX 작동 원리

### 2-1. Order Book (호가창)

CEX 의 매칭 framework — 호가창.

작동:
- 매도 호가: *"BTC 1개 $100,000 에 팔겠다"*
- 매수 호가: *"BTC 1개 $99,800 에 사겠다"*
- 호가가 만나면 거래 체결
- 호가 차이 (스프레드) = $200

### 2-2. 매수 시 일어나는 일

업비트에서 BTC 매수 클릭 시:
1. 사용자가 — 매수 주문 (시장가 또는 지정가)
2. 거래소 매칭 엔진이 — 가장 낮은 매도 호가 찾기
3. 거래 체결
4. 거래소 데이터베이스에 — 사용자 BTC 잔액 + 1
5. 거래소 데이터베이스에 — 사용자 KRW 잔액 - 매수 금액

중요 — *"실제 BTC 가 사용자 지갑에 들어오는 게 아님"*. 거래소 내부 데이터베이스 잔액만 변경.

### 2-3. 출금 시 일어나는 일

사용자가 자기 지갑으로 출금 시:
1. 거래소가 — 자기 콜드월렛에서 BTC 인출
2. 사용자 지갑으로 송금
3. 거래소 데이터베이스에 — 사용자 잔액 -

## 3. DEX 작동 원리

### 3-1. AMM (Automated Market Maker)

DEX 의 매칭 framework — AMM. 호가창 없음. 수학 공식만.

Uniswap 의 공식:
```
x × y = k
```
- x = 풀의 BTC 양
- y = 풀의 USDC 양
- k = 일정한 상수

### 3-2. 매수 시 일어나는 일

Uniswap 에서 BTC 매수 시:
1. 사용자가 — USDC 를 풀에 넣음
2. 풀에서 — 비트코인 (또는 WBTC) 빼냄
3. k 가 일정하도록 — BTC 가격 자동 조정
4. 사용자 지갑에 — BTC 직접 입금

DEX 의 차이 — *"사용자 자산이 자기 지갑에서 자기 지갑으로 직접"*. 중간자 X.

## 4. CEX vs DEX 비교

| 차원 | CEX | DEX |
|------|-----|-----|
| 운영 | 회사 | 스마트 컨트랙트 |
| 자산 보관 | 거래소 | 사용자 자기 지갑 |
| 매칭 | Order Book | AMM |
| KYC | 의무 | 없음 (대부분) |
| 속도 | 빠름 | 느림 (블록체인) |
| 수수료 | 약 0.05-0.25% | 약 0.05-0.5% |
| 위험 | 거래소 해킹 + 파산 | 스마트 컨트랙트 버그 |

## 5. 한국 사용자 가이드

한국에서 — CEX 가 사실상 유일한 옵션:
- 업비트, 빗썸, 코인원, 코빗, 고팍스 (5대 거래소)
- VAUPA + 실명 계좌 의무
- DEX 사용은 — 합법이지만 — 트래블룰 + 세제 복잡

## 6. 학술적 의미

- CEX = *"전통 금융 친화"* — 사용자 친화 + 규제 친화
- DEX = *"가상자산 본질"* — 분산 + 검열저항 + 자가 보관

이 두 framework 의 trade-off 가 — 가상자산 학계의 가장 큰 토론 주제.

## 결론

**CEX = 호가창, 회사 운영, 자산 보관. DEX = AMM, 스마트 컨트랙트, 자가 보관. 한국은 CEX 우위.**
