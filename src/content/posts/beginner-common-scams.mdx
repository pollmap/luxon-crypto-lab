## 1. 러그풀 (Rug Pull)

### 1-1. 메커니즘

**러그풀** — 개발자가 — 토큰 발행 + 사용자 자금 모은 후 — 자금을 가지고 도망.

작동:
- 새 토큰 출시 + 마케팅
- 사용자가 매수 → 가격 상승
- 개발자가 — 자기 보유 토큰 + 유동성 풀 자금 가지고 사라짐
- 토큰 가격 -99% 폭락

### 1-2. 사례

- **Squid Game Token** (2021): K-드라마 *"오징어 게임"* 이름 활용. 가격 +80,000% → 0
- **OneCoin** (2014-2017): 글로벌 폰지, 약 $4B+ 손실
- 한국 — 다수 소규모 러그풀 (수백 케이스)

### 1-3. 방어

- 새 토큰 — 발행자 신원 확인
- 유동성 잠금 (LP locked) 확인
- 백서 + 팀 + 로드맵 검증

## 2. 폰지 사기 (Ponzi)

### 2-1. 메커니즘

**폰지** — 새 사용자의 자금으로 — 기존 사용자에게 *"수익"* 지급. 자금 유입 멈추면 — 붕괴.

작동:
- *"고수익 보장"* 광고
- 새 사용자 자금 → 기존 사용자에게 분배
- 자금 유입 둔화 → 지급 중단 → 붕괴
- 다수 사용자 손실

### 2-2. 사례

- **Bitconnect** (2016-2018): *"매일 1% 이자 보장"*. 약 $2B+ 손실
- **PlusToken** (2018-2020): 중국 폰지, 약 $3B+ 손실
- **한국 다수 사례**: V글로벌, EvenStar 등

### 2-3. 방어

- *"무위험 고수익 보장"* = 사기 신호
- 수익 출처 명확하지 않음 → 의심
- 빠른 출금 막힘 → 위험 신호

## 3. 피싱 (Phishing)

### 3-1. 메커니즘

**피싱** — 가짜 사이트 + 메시지로 사용자 정보 탈취.

흔한 패턴:
- *"Etherscan 로그인 필요"* 가짜 사이트
- *"MetaMask 업데이트"* 가짜 알림
- *"한국 거래소 인증"* 가짜 SMS
- *"지갑 동기화 필요"* 가짜 메시지

### 3-2. 사례

- *"Wallet Connect 사기"* — 가짜 dApp 이 사용자 지갑 권한 요청
- *"DAO 투표 사기"* — 가짜 거버넌스 제안에 서명 → 자금 유출
- *"Airdrop 사기"* — 가짜 에어드랍 클레임 → 시드 구문 탈취

### 3-3. 방어

- 시드 구문 — 어디에도 입력 X (정식 사이트도)
- URL 직접 입력 (북마크 활용)
- 웹사이트 인증서 확인
- 이메일/SMS 의 링크 클릭 X

## 4. 가짜 거래소

### 4-1. 메커니즘

가짜 거래소가 — 실제 거래소처럼 위장. 사용자 자금 입금 → 출금 막힘.

### 4-2. 사례

- 한국에서 — 가짜 *"업비트 글로벌"*, *"빗썸 프리미엄"* 등 다수
- 글로벌에서 — *"Binance Korea"* 같은 가짜 도메인

### 4-3. 방어

- 공식 사이트 직접 접속 (검색 X)
- 실명 계좌 연동 가능한 5 거래소만 사용 (한국)
- 글로벌 거래소 직접 검색 + 인증서 확인

## 5. 가짜 지원 사기

### 5-1. 메커니즘

*"고객 지원"* 위장 사기:
- 사용자가 — 거래소 + 지갑 문제 호소 (Twitter, Discord)
- 가짜 *"지원 직원"* 이 — DM 보냄
- 시드 구문 + 비밀번호 요청

### 5-2. 방어

- 진짜 지원은 — 시드 구문 절대 안 묻음
- 공식 사이트 외 지원 X
- DM 모두 의심

## 6. 한국 사기 케이스

한국에서 흔한 사기:
- *"고수익 보장 코인 투자 카톡방"* — 다수 폰지
- *"가상자산 + 부동산 결합"* 광고
- *"교회 + 종교 단체 가상자산"*
- *"지인 추천"* 사기

금감원이 — 정기 위험경보 발동.

## 7. 자기 방어 표준

가상자산 사용 시 반드시:

1. **시드 구문 — 어디에도 입력 X** (정식 사이트, 지원 직원 모두 X)
2. **공식 URL 만 사용** (북마크 + 검색 X)
3. ***"고수익 보장"* = 사기**
4. **DM + SMS 의 링크 클릭 X**
5. **2FA (이중 인증) 필수**
6. **콜드 월렛 + 자가 보관**
7. **금감원 위험경보 모니터링**

## 결론

**5 사기 패턴 (러그풀 + 폰지 + 피싱 + 가짜 거래소 + 가짜 지원). 자기 방어 7 표준 준수.**
