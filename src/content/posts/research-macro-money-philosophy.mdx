## 도입 — *"BTC 화폐론 의 3 framework"*

비트코인을 *"화폐"* 로 분석하는 학술 framework — 3 가지 주류:

1. **Lyn Alden** — 매크로 분석가, *"Broken Money"* 4단계 진화
2. **Saifedean Ammous** — 오스트리아 학파 경제학자, *"Bitcoin Standard"*
3. **George Selgin** — 자유은행 학파, *"Synthetic Commodity Money"*

본 편은 3 framework 비교.

## 1. Lyn Alden — Broken Money (2023)

### 1-1. 4단계 화폐 진화
| 단계 | 시기 | 형태 |
|------|-----|------|
| 1. 상품 화폐 | ~1600 이전 | 금·은·곡식 |
| 2. 대표 화폐 | 1600-1971 | 금태환 지폐 |
| 3. 명목 화폐 | 1971- | 신용 화폐 |
| 4. 디지털 희소성 | 2009- | BTC |

### 1-2. 핵심 명제
명목 화폐의 결함 — 정부 무제한 발행. BTC 가 *"21M 한도"* 로 이를 해결.

### 1-3. 매크로 framework
M2 + DXY + 금리 와 BTC 가격 회귀. R² 0.87 (2018-2024). #1-C 에서 자세히.

## 2. Saifedean Ammous — The Bitcoin Standard (2018)

### 2-1. 오스트리아 학파
Friedrich Hayek + Ludwig von Mises 의 학파. 핵심 명제:
- 화폐 시스템은 정부 통제에서 벗어나야 함
- 인플레이션은 본질적 도덕 결함
- 금 본위제가 자연 화폐

### 2-2. BTC = 디지털 금
Ammous 의 framework — BTC 가 *"디지털 금"* 으로 금의 한계 (운송, 검증)를 극복. *"Bitcoin Standard"* 가 미래의 자연 화폐 시스템.

### 2-3. 비판
오스트리아 학파의 학술적 위치 — *"non-mainstream"*. 케인지언 + MMT 가 학계 주류. Ammous 의 framework 가 광범위 인기 있지만 학계 검증 어려움.

## 3. George Selgin — Synthetic Commodity Money (2015)

### 3-1. 자유은행 학파
Cato Institute + George Mason 대학교. 핵심 명제:
- 화폐 발행은 경쟁 시장에서 가능
- *"중앙은행 독점"* 이 문제
- *"private money"* (민간 화폐) 의 가능성

### 3-2. *"Synthetic Commodity Money"* 정의
Selgin 의 학술 분류:
- **Commodity money** — 자연 자산 (금, 은)
- **Fiat money** — 정부 발행 (USD, KRW)
- **Synthetic commodity money** — *"인공 희소성"* (BTC, USDT)

이 새 카테고리가 학술적 기여. 비트코인 학계의 표준.

### 3-3. 21M 의 *"임의 숫자"* 시각
Selgin 의 비판 — *"21M 이 화폐사적 필연이 아니라 임의 숫자"*. #1-A 에서 자세히. Alden + Ammous 와 차별.

## 4. 3 framework 비교

| 차원 | Alden | Ammous | Selgin |
|------|-------|--------|--------|
| 학파 | 매크로 분석 | 오스트리아 | 자유은행 |
| BTC = | 디지털 희소성 | 디지털 금 | Synthetic commodity |
| 정부 인플레이션 | 비판 | 강한 비판 | 부분 비판 |

| 학계 위치 | 매크로 인용 다수 | 비주류 | 학술 표준 |

## 5. 3 framework 의 실무 함의

### 5-1. 매크로 trader (Alden)
M2, DXY, Fed 정책으로 BTC 가격 forecast. Bridgewater + 헤지펀드의 framework.

### 5-2. HODLer (Ammous)
영구 보유 + *"insurance against fiat collapse"*. Strategy + Metaplanet 의 framework.

### 5-3. 학자 (Selgin)
정량 검증 + 비판적 시각. NY Fed 1052 + BIS WP 1280 의 framework.

## 6. 한국 시장에 적용

### 6-1. 한국에서 가장 강한 framework
한국 사용자 다수가 — Ammous framework (HODL + 디지털 금) 채택. 단순 + 직관적.

### 6-2. 한국 매크로 분석가
일부 한국 분석가 (한국은행 BOK Issue 9 등) 가 — Alden framework 적용. 매크로 변수와 BTC 회귀.

### 6-3. 한국 학계
Selgin framework 가 한국 학계의 인용 1순위. *"synthetic commodity money"* 가 학술 표준.
