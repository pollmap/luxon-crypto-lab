## 도입 — *"L2 의 본질"*

자, L2 (Layer 2) 강의를 시작합시다. *"L2"* 가 무엇인지부터.

이더리움의 본질적 한계가 — *"확장성(scalability)"* 입니다. 이더리움 메인넷이 — 초당 약 15-30 TPS (transactions per second). Visa 의 1,700 TPS 대비 매우 낮음. 이게 — 이더리움 가스비 폭등의 원인.

해결책이 — L2 (Layer 2):
- L2 가 — 별도 체인에서 트랜잭션 처리
- 결과만 — 이더리움 메인넷 (L1) 에 게시
- 보안은 — L1 에 의존
- 자체 처리 효율 + L1 보안 결합

이게 *"Rollup"* 학술 framework. Vitalik Buterin 이 — 이더리움의 미래로 *"Rollup-centric roadmap"* 을 발표 (2020).

오늘은 — Rollup 의 두 종류 중 *"Optimistic Rollup"* 의 1위 — Arbitrum 을 깊이 봅니다.

## 1. Optimistic vs ZK Rollup — *"두 학술 답"*

### 1-1. 두 종류의 비교

L2 의 두 종류:

**Optimistic Rollup**:
- 트랜잭션이 *"기본 valid"* 라고 가정
- 7일 challenge 기간 — 이의제기 가능
- 이의제기 시 — *"fraud proof"* 검증
- 예: Arbitrum, Optimism, Base

**ZK Rollup**:
- 모든 트랜잭션에 *"ZK proof"* 첨부
- 즉시 검증 + 즉시 finality
- 더 복잡한 학술 framework
- 예: zkSync, Linea, Scroll, Polygon zkEVM

### 1-2. 두 모델의 trade-off

Optimistic Rollup:
- 장점: 학술적 단순, 인프라 빠르게 구축
- 단점: 7일 출금 지연

ZK Rollup:
- 장점: 즉시 finality, 더 강한 보안 보장
- 단점: 학술적 복잡, 인프라 구축 어려움

이 두 모델의 학술 비교가 — L2 학계의 표준 토론 주제.

## 2. Arbitrum 의 출발

### 2-1. Offchain Labs

Arbitrum 의 회사 — *"Offchain Labs"*. Princeton 학자 Ed Felten + 학생 들이 2018년 창립. 학술적 배경이 강함.

### 2-2. Arbitrum One 출범

2021년 8월 — Arbitrum One 메인넷 출시. 첫 Optimistic Rollup 메인넷.

### 2-3. 시장 점유

빠르게 성장:
- 2022 TVL $1B
- 2023 TVL $2B
- 2024 TVL $3B
- 2026 TVL 약 $3-5B (Optimistic Rollup 1위)

## 3. Nitro — *"Arbitrum 의 진화"*

### 3-1. Nitro 가 무엇인가

2022년 8월 — Arbitrum 이 *"Nitro"* 업그레이드. 학술 + 기술 도약:
- Geth (Ethereum 클라이언트) 직접 활용
- 가스비 약 50% 절감
- 더 빠른 트랜잭션 처리

### 3-2. 학술적 의미

Nitro 가 — Optimistic Rollup 의 학술 표준이 됐습니다. 다른 Optimistic Rollup (Optimism Bedrock, Base) 도 — Nitro 의 디자인 영향.

## 4. Stylus — *"WASM 컨트랙트"*

### 4-1. Stylus 가 무엇인가

2024년 — Arbitrum 이 *"Stylus"* 출시. 핵심:
- Rust, C, C++ 등 WASM 호환 언어로 스마트 컨트랙트 작성 가능
- Solidity 대비 — 가스비 약 10-100배 절감
- 더 강력한 성능

### 4-2. 학술적 의미

Stylus 가 — *"스마트 컨트랙트 언어 다양화"* 의 첫 대규모 사례. Ethereum 의 Solidity 단일성을 — 다중 언어로 확장.

이게 — Cornell IC3 + Stanford CBR 의 학술 분석 활발 분야.

## 5. ARB 토큰 — *"가치 포착"*

### 5-1. ARB 의 역할

ARB 토큰 (2023년 3월 출시):
- Arbitrum DAO 거버넌스
- 사용자에게 에어드롭 (시가 약 $1B+ 분배)
- L2 토큰 중 가장 큰 에어드롭

### 5-2. 가치 포착의 한계

ARB 의 가치 포착이 — UNI, COMP 처럼 약함:
- 거래 수수료 분배 X
- 가스비 수익이 — Arbitrum DAO 로 들어감
- ARB 보유자가 받는 실질 수익 부족

### 5-3. 학술적 평가

ARB 가 — *"L2 거버넌스 토큰의 가치 포착 결핍"* 의 사례. 다수 학자가 — Fee Sharing 활성화를 권고.

## 6. Arbitrum 의 학술 영향

### 6-1. L2 학계의 핵심 자료

Arbitrum 데이터가 — L2 학술 분석의 핵심:
- BIS Working Paper (2024)
- Stanford CBR 분석
- Cornell IC3 보안 연구
- L2Beat 의 학술 통계

### 6-2. 한국 학자에게의 의미

한국 학자가 — L2 연구할 때 Arbitrum 부터 시작. KAIST + 서울대의 블록체인 연구실에서 — Arbitrum 분석 활발.

<Callout type="opposing-view" title="반대 시각 · Arbitrum 의 *7일 출금 지연*">
Arbitrum 의 비판:

첫째, ***"7일 출금 지연"***. Optimistic Rollup 의 본질적 한계. 사용자가 L2 → L1 출금에 7일 대기.

둘째, ***"ARB 가치 포착 약함"***. 사용자 + LP 가 거래 수수료 부담하지만, ARB 보유자가 받는 수익 0.

셋째, ***"중앙집중 sequencer"***. Arbitrum 의 sequencer 가 — 단일 entity (Offchain Labs) 가 운영. 학술적 분산성 우려.

넷째, ***"ZK Rollup 의 위협"***. 장기적으로 — ZK Rollup 의 학술 + 기술 우위가 Optimistic Rollup 을 대체할 가능성.

이 비판이 의미하는 바 — Arbitrum 이 *"현재 Optimistic Rollup 1위"* 로는 가치 있되, *"장기 우위"* 는 학계가 회의적.
</Callout>
