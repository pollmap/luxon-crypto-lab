## 1. NFT 가 무엇인가

**NFT = Non-Fungible Token (비대체성 토큰)**. *"각자 다른"* 토큰.

비교:
- **Fungible (대체성)**: BTC. 1 BTC = 1 BTC. 어떤 BTC 든 동일.
- **Non-Fungible (비대체성)**: NFT. 각 NFT 가 — 고유한 ID + 메타데이터.

## 2. NFT 의 사용 사례

### 2-1. 디지털 아트

가장 큰 사용 사례. CryptoPunks, BAYC (Bored Ape) 등.

### 2-2. 게임 아이템

게임 내 아이템을 NFT 로. Axie Infinity, Big Time 등.

### 2-3. 음악 + 콘텐츠

음악, 영화, 책 등을 NFT 로. Royal, Sound.xyz.

### 2-4. 신원 + 자격

POAP (참석 증명), 학위 NFT.

### 2-5. RWA (Real-World Asset)

부동산, 미술품, 명품 등을 NFT 로. 학술적으로 가장 큰 잠재력.

## 3. ERC-721 표준

이더리움 NFT 의 표준:
- 각 NFT 가 — 고유한 ID (1, 2, 3...)
- 메타데이터 (이미지, 이름, 속성) 가 별도 저장
- 일반적으로 IPFS 또는 Arweave 에 메타데이터

ERC-1155 — 다중 NFT 가 한 컨트랙트 (게임 아이템 다양 종류)

## 4. NFT 의 가치 논쟁

NFT 가 *"진짜 가치"* 가 있는지 — 학술 토론 활발.

### 4-1. 가치 옹호 시각

- 디지털 소유권의 첫 실현
- 글로벌 미술 시장 진출
- IP holder 수익 다각화

### 4-2. 가치 비판 시각

- 이미지가 — 누구나 복사 가능 (블록체인은 *"소유권"* 만 기록)
- 거품 + 폰지 위험
- 사용 사례 미진

### 4-3. 학술적 평가

대부분 학자가 — *"NFT 거품 (2021) 후 사용 사례 정착 (2024-)"*. RWA + 게임 + 신원 분야가 미래 가능성.

## 5. NFT 시장 변동

### 5-1. 2021 거품

- 약 $40B+ 거래량 (2021 Q3)
- BAYC #2087 — 약 $2.5M 거래
- CryptoPunk #5822 — 약 $24M 거래

### 5-2. 2022-2023 침체

- 거래량 약 90%+ 하락
- 다수 NFT 가 — 가격 -95%
- 대부분 사용자 손실

### 5-3. 2024-2026 정착

- 거래량 회복 약 20-30% 수준
- RWA + 게임 NFT 활성화
- 투기 거품 → 사용 사례 시대

## 6. 한국 NFT 시장

한국 NFT 진출 사례:
- **카카오 (Klaytn)** — 2021 적극 진출, 2023 정리
- **라인 NEXT (DOSI)** — 글로벌 NFT 마켓플레이스
- **11번가** — 시도 후 2023 종료
- **SK 텔레콤** — Topport NFT, 정리

한국 NFT 시장이 — 글로벌 거품 + 침체에 함께 영향.

## 7. NFT 의 미래

학술 토론:
- RWA NFT (BlackRock BUIDL 등) 의 정착
- 게임 NFT 의 진화
- 신원 NFT (POAP, SBT) 의 학술 framework
- BTC Ordinals 의 NFT 진출

자세한 분석은 — NFT 시리즈 (Phase 5) 참조.

**NFT = 비대체성 토큰. 디지털 소유권. 2021 거품 + 2023 침체 + 2024 정착. RWA + 게임 + 신원이 미래.**
