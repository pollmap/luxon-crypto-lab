## 도입 — *"알트시즌"* 이라는 단어의 정량 정의

가상자산 산업에서 가장 자주 사용되지만 가장 모호한 단어 — *"알트시즌(Altseason)"*. 일반적으로 *"BTC 외 다른 코인이 가속하는 시기"* 를 뜻하지만, *"몇 % 가속해야 알트시즌인가"* 의 정량 기준이 부재.

Coinglass 가 2022년 *"Alt-Coin Season Index"* 를 발표하면서 학술적 정의를 시도. **75% 기준** — *"top 50 코인 중 75% 이상이 90일 동안 BTC 를 outperform 하면 알트시즌"*. 이게 가장 널리 사용되는 정량 정의.

본 편은 5섹션 — (1) BTC Dominance 의 정의, (2) 알트시즌 75/25 framework, (3) 사이클의 4 phase, (4) 한국 투자자 패턴, (5) 학계 비판 — 으로 정리.

## 1. Bitcoin Dominance (BTC.D) — 정의 + 한계

### 1-1. 정의
<Formula>{`BTC.D = BTC 시가총액 / 전체 가상자산 시가총액`}</Formula>
2026 Q1 기준:
- BTC 시총 ~$2T
- 전체 가상자산 시총 ~$3.6T
- BTC.D = ~55.5%

### 1-2. 역사 변화
| 시점 | BTC.D |
|------|-------|
| 2013 (이전) | 95%+ (BTC 외 거의 X) |
| 2014.6 | 94% |
| 2017.6 (ICO 광풍) | 38% |
| 2018.1 | 33% (역사 저점) |
| 2020.12 | 71% |
| 2021.4 (DeFi/NFT) | 41% |
| 2022.5 (Luna 후) | 47% |
| 2024.1 (ETF) | 53% |
| 2026.1 | **55.5%** |

BTC.D 의 변화가 — *"BTC 가 잘하는가 vs 알트가 잘하는가"* 의 단순 비교.

### 1-3. 한계
BTC.D 의 한계 4가지:
- **스테이블코인 포함** — USDT $190B + USDC $77B 가 *"가상자산"* 으로 포함되면 BTC.D 가 약간 왜곡
- **시총 X 거래량** — 시총이 크지만 거래량이 작은 coin (XRP 일부 시기) 가 BTC.D 를 부풀림
- **에코시스템 차이** — ETH + L2 의 결합이 BTC 와 비교 가능한가
- **카테고리 다양성** — Meme, AI, RWA, DeFi 가 모두 *"알트"* 로 합산. 카테고리별 분리 필요

이 한계로 BTC.D 만으로는 시장 분석 부족. 여기서 *"알트시즌 인덱스"* 가 보완.

## 2. 알트시즌 75/25 Framework

### 2-1. Coinglass 정의
Coinglass 의 알트시즌 인덱스:
1. Top 50 코인 (시총 기준, 스테이블 + BTC 자체 제외) 선정
2. 90일 가격 변화 측정
3. BTC 보다 outperform 한 코인 비율 계산
4. **75% 이상 outperform = 알트시즌**, **25% 미만 = BTC 시즌**, 25-75% = 중립

### 2-2. 인덱스 점수
인덱스를 0-100 으로 변환:
- 100 = 모든 코인이 BTC outperform
- 75 = 75% outperform (알트시즌 임계)
- 50 = 절반 outperform (중립)
- 25 = 25% 미만 (BTC 시즌)
- 0 = 어떤 코인도 outperform X

### 2-3. 역사 검증
| 시점 | 인덱스 점수 | 단계 |
|------|-----------|------|
| 2017.12 (ICO peak) | 92 | 알트시즌 |
| 2018.1 (top) | 87 | 알트시즌 |
| 2018.12 (bottom) | 14 | BTC 시즌 |
| 2020.3 (COVID) | 24 | BTC 시즌 |
| 2021.4 (DeFi) | 81 | 알트시즌 |
| 2022.6 (Luna 후) | 18 | BTC 시즌 |
| 2024.1 (ETF) | 32 | BTC 시즌 |
| 2024.11 | 68 | 중립 (알트 가속 시작) |
| 2025.4 | 78 | 알트시즌 |
| 2026.1 | 45 | 중립 |

이 인덱스가 사이클 단계 식별의 학술 표준이 됐습니다.

## 3. 사이클의 4 Phase Framework

학계 (Glassnode, Kaiko 2025) 가 정리한 *"Crypto Cycle 4 Phase"*:

### 3-1. Phase 1 — *"BTC pump"*
- 사이클 초기, BTC 가 먼저 가속
- BTC.D 상승 (~50% → ~58%)
- 알트시즌 인덱스 25 미만
- 사용자 행동 — BTC 매수, 알트 매도
- 역사 — 2024.1 ETF 출시 후 6개월

### 3-2. Phase 2 — *"BTC top + ETH catch-up"*
- BTC 가 상대적 peak 도달
- ETH 가 BTC 와 ratio (ETH/BTC) 가속
- BTC.D 하락 시작 (~58% → ~52%)
- 알트시즌 인덱스 30-55
- 사용자 행동 — BTC 일부 매도, ETH 매수
- 역사 — 2024.10-2025.1

### 3-3. Phase 3 — *"ETH pump + L2 + DeFi"*
- ETH + ETH 생태계 (L2, DeFi) 가속
- BTC.D 추가 하락 (~52% → ~45%)
- 알트시즌 인덱스 55-75
- 사용자 행동 — ETH 매수, L2 토큰 매수
- 역사 — 2025.1-2025.4

### 3-4. Phase 4 — *"All-altcoin pump"*
- 작은 cap 코인까지 가속 (Meme, AI, micro-cap)
- BTC.D 큰 하락 (~45% → ~38%)
- 알트시즌 인덱스 75+
- 사용자 행동 — 무차별 alt 매수 (FOMO)
- 역사 — 2017.12, 2021.4
- **Phase 4 가 사이클 정점 = 일반적으로 다음에 폭락**

이 4 phase 가 *"순서대로"* 진행. Phase 1 → 2 → 3 → 4. 그 후 새 사이클 시작.

## 4. 한국 투자자 패턴 — 알트 선호

### 4-1. 한국 거래소 거래량 분포
한국 거래소 (업비트, 빗썸) 의 거래량 분포:

| 코인 | 한국 거래량 비중 (글로벌 대비) |
|------|-------------------|
| BTC | 8% |
| ETH | 11% |
| XRP | 22% (한국이 글로벌 1위) |
| DOGE | 18% |
| SOL | 14% |
| 메이저 알트 | 평균 16% |

**한국이 알트 시장에서 글로벌 점유율의 평균 16%**. 즉 한국 투자자의 *"알트 선호"* 가 정량적.

### 4-2. 김치 프리미엄과의 결합
김치 프리미엄 (한국 가격 - 글로벌 가격) 이 알트에서 더 큼:
- BTC 김치 프리미엄 평균 +3-5%
- 알트 김치 프리미엄 평균 +6-12%

이 격차가 *"한국 알트시즌"* 이 글로벌 알트시즌보다 1-2개월 늦게 정점 도달하는 이유.

### 4-3. 한국 알트시즌 시작 신호
한국 시장에서 알트시즌의 시작 신호:
1. **업비트 거래량 BTC 비중 < 30%** (정상 시 ~50%)
2. **신규 가입 사용자 가속**
3. **김치 프리미엄 +5% 이상**
4. **소액 코인 (시총 ~$100M) 가속**

이 4 신호가 동시 나타나면 *"한국 알트시즌 임박"*.

## 5. 학계의 한계 분석

### 5-1. 75% 기준의 임의성
*"75% outperform"* 의 75 라는 숫자가 임의적. 70% 또는 80% 라면 다른 결과. Coinglass 가 75% 를 선택한 이유는 *"역사 데이터에 가장 잘 fit"* 이지만, 학술적 정당성은 약합니다.

### 5-2. 90일 window 의 한계
90일 비교가 *"단기 momentum"* 만 capture. *"장기 cycle"* (2-3년) 의 신호와 다를 수 있음.

### 5-3. Top 50 의 변화
Top 50 코인이 시간에 따라 변화. 새로운 토큰 (AI, RWA 등) 이 들어오고 기존 토큰 (Filecoin, IOTA 등) 이 빠집니다. 이 *"composition change"* 가 알트시즌 비교의 정확도를 떨어뜨림.

<Callout type="opposing-view" title="반대 시각 · 알트시즌 framework 의 학술적 한계">
알트시즌 인덱스 + 4 phase framework 가 직관적이지만, 비판적 시각이 강합니다.

첫째, **사후 정당화 편향 (post-hoc rationalization)**. 4 phase 가 역사 데이터에서 식별 가능하지만, *"미래 phase 식별"* 의 정확도가 낮음. 2024년 Phase 1 인 줄 알았던 시점이 사실 Phase 2 였을 수도. 실시간 식별 어려움.

둘째, **ETF 시대의 patterns 다를 가능성**. 2024 ETF 출시 후 BTC 의 *"기관 매수 dominance"* 가 종전 사이클 패턴과 다름. 4 phase 가 *"retail 위주"* 사이클의 framework. ETF 시대에는 phases 가 더 짧거나, 길거나, 다른 순서일 가능성.

셋째, **알트 카테고리의 분화**. 2024-2026 알트가 — Meme + AI + RWA + DeFi + L2 등 매우 다양한 카테고리. *"알트시즌"* 이 단일 단계가 아니라 *"meme 시즌"* + *"AI 시즌"* + *"RWA 시즌"* 의 복수 단계로 분화 가능. 단일 인덱스로 capture 어려움.

넷째, **BTC Dominance 의 결정적 한계**. ETH + L2 의 결합 시총이 ETH 시총만 카운팅하면 BTC.D 가 인위적으로 높음. 즉 *"BTC.D 50% = BTC 우세"* 가 아닐 수 있음.

다섯째, **김치 프리미엄 + 한국 패턴의 unique character**. 한국 시장이 글로벌 평균과 다른 패턴. 글로벌 알트시즌 인덱스가 한국 사용자에게 정확하지 않을 수 있음. 한국 자체 인덱스가 필요.

이 5가지 비판이 의미하는 바 — 알트시즌 framework 가 *"좋은 starting point"* 이지만 *"trading 결정"* 의 single signal 로 의존하면 위험합니다.
</Callout>

## 결론 — 정량 framework 의 학술적 위치

본 편이 정리한 5가지 핵심 발견:

1. **BTC.D = BTC 시총 / 전체 시총**. 단순하지만 4가지 한계 (스테이블, 거래량, 에코시스템, 카테고리).
2. **알트시즌 75/25 framework**. Coinglass 의 90일 window + 75% outperform 기준.
3. **사이클의 4 phase**. BTC pump → BTC top + ETH catch-up → ETH pump → all-alt pump.
4. **한국 알트 선호 + 김치 프리미엄**. 한국이 알트 글로벌 점유율 16%, 알트시즌 신호 4가지.
5. **학계 한계 5가지**. 75% 임의성 + 90일 window + Top 50 변화 + ETF 시대 패턴 + 한국 unique 패턴.
