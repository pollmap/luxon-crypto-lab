## 1. 이더리움이 무엇인가

**이더리움(Ethereum, ETH)은 비트코인과 다른 자산 클래스**. 비트코인이 *"디지털 화폐"* 라면, 이더리움은 *"분산 컴퓨터"*.

비유로 풀면:
- BTC = 금. 가만히 있어도 가치 보존
- ETH = 정유사. 매일 작동하면서 가치 창출

(이 비유는 Bankless 의 Mike Ipolito 가 2022년 제안)

## 2. 왜 만들어졌나

이더리움의 출발 — 2014년 Vitalik Buterin (당시 19세 + 캐나다 + 러시아 출신) 의 백서.

Buterin 의 통찰:
- 비트코인이 *"전자 화폐"* 만 가능
- 그러나 — *"프로그래머블 화폐"* 가 가능하면 — 더 큰 가능성
- *"smart contract"* 라는 새 framework 제안

## 3. 어떻게 작동하나

### 3-1. 스마트 컨트랙트 (Smart Contract)

스마트 컨트랙트가 — 이더리움의 핵심 framework. 작동:
- 코드가 — 블록체인 위에 배포
- 코드가 — 자동으로 실행 (인간 개입 X)
- *"if X then Y"* 식의 규칙이 — 영구히 작동

예시:
- 보험 컨트랙트: *"비행기가 늦으면 자동 보상"*
- 대출 컨트랙트: *"담보 가치가 떨어지면 자동 청산"*
- DAO: *"투표 결과에 따라 자동 자금 분배"*

### 3-2. EVM (Ethereum Virtual Machine)

EVM 이 — 모든 이더리움 검증자가 실행하는 *"가상 컴퓨터"*. 같은 입력 → 같은 결과 보장.

이게 *"분산 컴퓨터"* 의 본질. 전 세계 검증자가 — 같은 코드를 실행하면서 합의에 도달.

### 3-3. 가스 (Gas)

이더리움 사용 시 — *"가스비(gas fee)"* 부담. 가스 = 컴퓨팅 비용.

작동:
- 트랜잭션마다 — 가스 소비
- 가스 가격 × 가스 양 = 수수료
- 사용자가 — 가스비 ETH 로 지불
- 검증자가 — 가스비 받음

## 4. The Merge — *"PoS 전환"*

2022년 9월 — 이더리움이 *"The Merge"* 로 PoS (Proof of Stake) 전환. 핵심 변화:

**전환 전 (PoW)**:
- 마이너가 — 컴퓨터 계산으로 합의
- 비트코인과 같은 framework

**전환 후 (PoS)**:
- 검증자가 — ETH 32 스테이킹
- 블록 생성 + 검증
- 보상 받음 (연 3-5%)
- 에너지 소비 99%+ 감소

이게 — 가장 큰 가상자산 인프라 변화 중 하나.

## 5. 이더리움의 사용 사례

이더리움 위에서 — 다양한 사용 사례:

1. **DeFi (Decentralized Finance)** — Aave, Uniswap, Curve 등 분산 금융
2. **NFT** — 디지털 소유권. OpenSea 등
3. **DAO** — 분산 자율 조직
4. **L2** — Arbitrum, Optimism, Base 등 확장
5. **RWA** — BlackRock BUIDL 등 실물자산 토큰화

이 다양성이 — *"디지털 정유사"* 비유의 핵심.

## 6. 이더리움 가치 포착

이더리움 토큰 (ETH) 의 가치 포착:

**EIP-1559 (2021)**:
- 기본 수수료 (base fee) 가 자동 소각
- 즉, 사용량이 많으면 — ETH 공급 감소
- *"deflationary money"* 가설

**Staking yield**:
- 검증자가 — 연 3-5% 보상
- 일반 사용자도 — Lido, Rocket Pool 같은 LST 로 참여 가능

이 두 메커니즘이 — ETH 의 *"디지털 정유사 + 합성 채권"* 의 학술 framework.
