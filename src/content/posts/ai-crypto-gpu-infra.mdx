## 1. DePIN (Decentralized Physical Infrastructure Networks)

### 1-1. 정의
물리적 인프라 (GPU, 스토리지, 통신) 를 분산 네트워크로 운영. Render (#A1), Filecoin, Helium 등.

### 1-2. AI 시대의 DePIN
2023-2026 AI 학습 + 추론 수요 가속. AWS GPU 인스턴스 부족. DePIN 이 대안.

## 2. 3 GPU DePIN

### 2-1. io.net
| 지표 | 2026 Q1 |
|------|---------|
| 활성 GPU 노드 | ~28,000 |
| 일 GPU-시간 | ~580K |
| H100 시간 가격 | ~$1.50 |
| IO 시총 | ~$1.4B |

### 2-2. Akash Network
컨테이너 기반 분산 컴퓨팅. CPU + GPU 모두. 작은 규모.

### 2-3. Render Network (#A1)
3D 렌더링 + AI 학습. 가장 큰 점유율.

## 3. AWS 와의 비교

| 지표 | AWS H100 | DePIN |
|------|---------|-------|
| 시간당 가격 | ~$4.0 | $1.5-2.5 |
| 신뢰성 | 매우 높음 | 보통 |
| 지원 | 24/7 | 제한적 |
| 글로벌 가용 | 100+ region | 작음 |

DePIN 가격이 50% 저렴. 그러나 *"신뢰성 + 지원"* 의 trade-off.

## 4. 사용 사례

- 작은 회사 + 개인 학습자 — 비용 우선 (DePIN)
- 대기업 + 연구소 — 신뢰 우선 (AWS)
- 가상자산 산업 자체 — DePIN 친화 (Render 가 Stable Diffusion 학습)

<Callout type="opposing-view" title="반대 시각 · DePIN 의 한계">
첫째, **AWS H100 가격 인하**. AWS 가 점차 가격 인하. DePIN 의 가격 우위 약화 가능.

둘째, **DePIN 의 *"신뢰 부재"*** 가 큰 학습 사용처 진입 barrier.

셋째, **NVIDIA H100 의 *"export control"***. 미국이 NVIDIA H100 중국 수출 금지. DePIN 이 글로벌 분산성으로 우회 가능 vs 미국 정부 단속 가능.

이 비판이 의미 — DePIN 이 *"틈새 시장"* 이지 *"AWS 대체재"* 가 아닐 가능성.
</Callout>
