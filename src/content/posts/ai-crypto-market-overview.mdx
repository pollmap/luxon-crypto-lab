## 도입 — "AI 코인" 이라는 카테고리의 정의 어려움

2024-2026 글로벌 가상자산 시장에서 가장 빠르게 성장한 카테고리가 "AI×Crypto" 또는 "AI 코인". Messari 의 "AI×Crypto Sector" 시총 변화:

| 시점 | AI×Crypto 시총 | 글로벌 가상자산 대비 |
|------|----------------|--------------------|
| 2023 Q1 | $1.8B | 0.2% |
| 2024 Q1 | $14B | 0.7% |
| 2025 Q1 | $32B | 1.4% |
| 2026 Q1 | $58B | 2.1% |

3년 만에 약 **32배 증가**. 그러나 "AI 코인" 이라는 카테고리 자체가 정의가 어렵습니다. 어떤 토큰을 "AI" 로 분류해야 하는가? 학계의 4가지 framework:

1. **AI 모델 자체를 토큰화** (예: Bittensor 의 서브넷)
2. **AI 인프라 (GPU·데이터)에 토큰 사용** (예: Render, io.net)
3. **AI 에이전트의 결제 수단으로 토큰** (예: Fetch.ai)
4. **AI 시대의 신원 검증 토큰** (예: Worldcoin)

이 4 카테고리가 매우 다른 사업 모델인데도 같은 "AI×Crypto" 라벨로 묶입니다. 이게 학술적으로 분석을 어렵게 만듭니다. 본 편은 4 대표 프로젝트를 카테고리별로 분리해서 봅니다.

## 1. Bittensor (TAO) — 분산 AI 모델 시장

### 1-1. 메커니즘
Bittensor 는 "AI 모델 시장" 입니다. 누구나 AI 모델을 "서브넷" 으로 등록하면, Bittensor 의 검증 노드가 그 모델의 성능을 평가하고, 성능에 비례해 TAO 토큰을 보상.

핵심 구조 — **Yuma Consensus**. 검증 노드들이 각자 모델 성능을 평가한 점수를 "중앙 평균" 으로 모은 후, 그 평균에 가까운 검증 노드에게 더 많은 보상. 이게 "평가의 진정성" 을 인센티브화 하는 게임이론적 메커니즘.

### 1-2. 서브넷
2026 Q1 기준 Bittensor 위 활성 서브넷 약 **78개**. 각 서브넷이 다른 AI 작업:
- 서브넷 1 — 텍스트 생성 (LLaMA 기반)
- 서브넷 3 — 이미지 생성 (Stable Diffusion)
- 서브넷 5 — 텍스트 임베딩
- 서브넷 18 — 코드 생성 (Cortex)
- 서브넷 51 — 의료 영상 분석
- 등...

서브넷 등록 비용 — 약 100,000 TAO (~$45M, 2026 Q1). 진입 장벽이 매우 높습니다.

### 1-3. 실제 사용량
이게 학술적으로 가장 큰 의문 — "Bittensor 의 AI 모델이 실제로 사용되는가". 2026 Q1 데이터:

| 지표 | 값 |
|------|---|
| TAO 시총 | ~$8.2B |
| 일 외부 API 호출 (서브넷 1) | ~120만 |
| 일 외부 API 호출 (전 서브넷) | ~280만 |
| OpenAI 일 API 호출 (비교) | ~약 10억+ |

Bittensor 의 일 사용량이 OpenAI 의 약 0.3% 수준. 즉 시총 $8.2B 인데 사용량은 매우 작습니다. 학계 일부가 "speculation > utility" 라고 평가하는 근거.

### 1-4. 토크노믹스 결함
TAO 는 4년마다 반감기 (Bitcoin 모방). 그러나 비트코인과 다르게 — TAO 채굴자(=검증 노드 + AI 서브넷 운영자) 의 경제 활동이 "실제 수익" 을 만들지 않습니다. 단순히 평가 + 보상의 game. 이게 비판적 시각의 핵심 — "TAO 는 어디서 가치를 받아오는가".

## 2. Render (RENDER) — 분산 GPU 렌더링

### 2-1. 메커니즘
Render Network 는 "여유 GPU" 를 가진 사람들과 "GPU 가 필요한 사람들" (3D 아티스트, 영화 스튜디오, AI 학습)을 연결하는 시장. RENDER 토큰이 결제 수단.

### 2-2. 사용 사례
- **3D 렌더링** (원래 사용처) — Blender, Maya, Cinema 4D 같은 도구로 만든 3D 모델의 렌더링
- **AI 모델 학습** (2024-2026 추가) — Stable Diffusion fine-tuning, LLaMA training
- **AI 추론** — ChatGPT 같은 모델의 inference

### 2-3. 실제 GPU 시간 사용량
| 지표 | 2024 Q4 | 2026 Q1 |
|------|---------|---------|
| 활성 GPU 노드 | 12,000 | 38,000 |
| 일 GPU-시간 | 120,000 | 480,000 |
| 일 RENDER 거래량 | 1.2M | 4.5M RENDER |
| RENDER 시총 | $4.1B | $5.8B |

Render 의 GPU 사용량이 가속하고 있습니다. 그러나 비교 — AWS 의 GPU 인스턴스 일 사용량 약 100M 시간 추정. **Render 의 GPU 시장 점유율 ~0.5%**. 작은 규모지만 실제 사용량이 있다는 점이 Bittensor 와 차이.

### 2-4. AWS 와의 가격 비교
| 서비스 | A100 GPU 시간당 가격 |
|--------|--------------------|
| AWS p4d.24xlarge (A100 8개) | ~$32/시간 (1 GPU 환산 ~$4.0) |
| **Render** | **~$1.8-2.5** |
| io.net | ~$1.5-2.0 |
| Akash | ~$1.2-1.8 |

Render 가 AWS 대비 약 50% 저렴. 그러나 "신뢰성, 지원, 성능 안정성" 측면에서 AWS 가 우월. 학술적으로 "price vs reliability" 의 trade-off.

## 3. Fetch.ai (FET → ASI) — AI 에이전트 결제

### 3-1. ASI Alliance
2024년 7월, Fetch.ai + SingularityNET + Ocean Protocol 3 프로젝트가 "ASI Alliance" 로 통합. 토큰 ticker FET → ASI 로 변경. 시총 통합 약 $7.5B (2026 Q1).

### 3-2. 메커니즘
ASI 는 "AI 에이전트" 가 서로 거래하는 시장. 예 — 항공권 검색 에이전트가 호텔 예약 에이전트에게 정보를 사고 ASI 로 결제.

### 3-3. 실제 사용
2026 Q1 활성 AI 에이전트 약 **8,400개**. 일 에이전트간 거래 약 **18만 건**. 평균 거래 가치 약 0.05 ASI (~$0.06).

### 3-4. 회의적 평가
"AI 에이전트 결제" 가 정말 필요한가? 학계 논쟁:

- **긍정** (a16z 2026) — "agentic economy" 가 도래하면 AI 에이전트들이 자율적으로 결제할 필요. ASI 가 그 인프라 선점.
- **부정** (Princeton CITP 2025) — 현재 AI 에이전트 결제 다수가 "인간이 미리 설계한 단순 거래". 진정한 자율 에이전트 결제는 미래의 가능성.

이 논쟁이 ASI 의 valuation 의 핵심 변수.

## 4. Worldcoin (WLD) — 신원 검증 토큰

### 4-1. 메커니즘
Worldcoin 은 Sam Altman (OpenAI CEO) 이 공동 창업. 핵심 — "AI 시대에 진정한 인간을 검증하는 인프라". "Orb" 라는 디바이스가 사용자의 홍채 스캔. 그 데이터로 "World ID" 를 발급. AI 가 만든 가짜 신원 (deepfake, AI agent) 와 진정한 인간을 구별.

### 4-2. 실제 사용
| 시점 | World ID 발급 수 |
|------|-----------------|
| 2023 launch | 0 |
| 2024 Q1 | 350만 |
| 2025 Q1 | 1,200만 |
| 2026 Q1 | 2,800만 |

2,800만 명이 World ID 발급. 작지 않은 규모. 사용처 — 일부 dApp 의 "인간 검증", 일부 정부의 "디지털 신원 시범".

### 4-3. 개인정보 우려
홍채 스캔 = 가장 민감한 생체 인증 데이터. EU GDPR + 한국 개인정보보호법 + 다수 국가의 강한 규제. 한국은 2024년 9월 Worldcoin 공식 금지. 케냐, 스페인, 포르투갈 등도 부분/전체 금지.

이 규제가 Worldcoin 의 글로벌 확장의 가장 큰 장애. "기술적 가능성" 과 "법적 허용성" 사이의 큰 갭.

### 4-4. WLD 토크노믹스
World ID 발급 사용자에게 일정량의 WLD 토큰 부여. 이게 마케팅 인센티브. 현재 사용자 1인당 평균 ~25 WLD (~$50, 2026 Q1).

## 5. AI×Crypto 의 4 framework 비교

| 카테고리 | 대표 | 시총 (2026 Q1) | 핵심 질문 |
|---------|------|---------------|---------|
| **AI 모델 시장** | Bittensor | $8.2B | 사용량이 시총 정당화? |
| **GPU 인프라** | Render, io.net, Akash | 합계 $11B | AWS 와 경쟁 가능? |
| **AI 에이전트** | ASI Alliance | $7.5B | 자율 에이전트 결제 정말 필요? |
| **신원 검증** | Worldcoin | $5.8B | 규제 장벽 극복 가능? |

각 framework 가 다른 가설을 검증해야 합니다. 단일 답이 없습니다.

## 6. 학계의 비판 — "AI 가 정말 crypto 가 필요한가"

a16z 가 2026 "State of AI×Crypto" 보고서에서 9가지 "AI 가 crypto 를 필요로 하는 이유" 를 제시. 그러나 학계의 카운터:

### 6-1. "AI 학습 데이터의 출처 검증" 가설
주장 — AI 모델이 학습한 데이터의 출처를 블록체인에 기록하면 신뢰성 확보. 카운터 — 데이터 출처 검증은 "누가 기록했는가" 가 아니라 "데이터 자체가 정확한가" 의 문제. 블록체인이 데이터 진정성을 보장하지 않습니다.

### 6-2. "AI 모델 inference 의 검증" 가설
주장 — AI 모델이 "진짜 무거운 모델" 을 사용했는지 ZK proof 로 검증. 카운터 — ZK proof 의 계산 비용이 추론 자체보다 1,000배 이상. 실용성 낮음.

### 6-3. "AI 에이전트의 결제 인프라" 가설
주장 — AI 에이전트가 자율적으로 결제하려면 crypto 같은 "무허가 인프라" 필요. 카운터 — Stripe, PayPal 같은 기존 결제 인프라가 API 접근 + 자동화 충분히 지원. "무허가성" 자체가 AI 에이전트 사용처에서 큰 장점이 아닐 수 있음.

### 6-4. "GPU 분산" 가설
주장 — AI 학습용 GPU 의 분산화로 AWS 의 가격 독점 깨기. 카운터 — 분산 GPU 의 성능·신뢰성·지원이 AWS 보다 약함. 가격 차이가 학습 시간 손실로 상쇄될 가능성.

이 학계 카운터가 의미하는 바 — "AI 와 crypto 의 결합 가능성" 은 명백하지만, "결합 필요성" 은 학술적으로 약합니다. 다수의 AI×Crypto 프로젝트가 "가능성" 을 앞세우지만 "필요성" 을 입증하지 못한 채 시총만 부풀려져 있습니다.

## 7. ACP (Agent Commerce Protocol) — 새로운 시도

다음 편(#A2) 에서 자세히 다루지만, ACP 가 AI×Crypto 의 새로운 방향. Skyfire, Coinbase x402 같은 프로젝트가 "AI 에이전트 표준 결제 프로토콜" 을 제시. HTTP 의 402 Payment Required 응답을 활용.

ACP 의 의의 — "crypto 가 AI 에이전트를 위해 만들어진" 새로운 프로토콜. 종전 "AI 가 crypto 사용처가 되는" 가설과 반대 방향. 실제로 작동하는지는 2026-2028 검증.

<Callout type="opposing-view" title="반대 시각 · AI 코인은 새로운 dot-com 버블인가">
AI×Crypto 시총이 3년 만에 32배 증가한 것을 "실수요 가속" 으로 평가하는 시각이 있지만, 비판적 시각도 강합니다.

첫째, **수익 vs 시총 의 비대칭**. Bittensor 의 시총 $8.2B 인데 일 활성 사용자 수는 매우 적습니다. Render 의 시총 $5.8B 인데 GPU 시장 점유율 0.5%. 이런 비대칭이 "speculation pricing" 의 신호. 1999년 dot-com 버블의 핵심 패턴과 동일.

둘째, **Sam Altman 효과**. Worldcoin 의 시총 $5.8B 의 다수가 "Sam Altman 의 신뢰" 에 기반. 그러나 OpenAI 와 Worldcoin 은 별개 회사고, Altman 의 OpenAI 성공이 Worldcoin 의 사업 모델 정당성을 보장하지 않습니다. "the personality premium" 으로 학술적으로 평가.

셋째, **"AI" 라벨의 마케팅 효과**. 2023년 ChatGPT 출시 후 어떤 토큰이든 "AI" 라벨을 붙이면 시총이 10배 상승하는 패턴. 학계의 분석 — "crypto 토큰의 AI 라벨링" 효과는 평균 +180% (Princeton CITP 2025). 즉 "AI" 라벨 자체가 시장에서 가치 부풀리기.

넷째, **글로벌 거시 변수와 동조화**. AI×Crypto 시총이 비트코인 사이클과 약 0.85 상관계수. 즉 AI×Crypto 가 "독립적 자산 클래스" 가 아니라 "비트코인 사이클의 hyper-beta version". 변동성은 더 크지만 fundamentals 는 약함.

다섯째, **유틸리티 vs 토큰의 분리**. 진정한 AI 발전은 OpenAI, Anthropic, Google DeepMind 같은 "중앙화된 회사" 들에서 이루어집니다. AI×Crypto 토큰들은 그 발전과 별개로 진행. "진짜 AI" 와 "AI 토큰" 의 격차가 점점 벌어집니다.

이 5가지 비판이 의미하는 바 — "AI×Crypto 가 새로운 자산 클래스인가" 라는 질문에 학술적 답은 "아직 미정" 입니다. 시총 가속이 검증된 사용처에서 오는 것인지, 아니면 단순 "AI 라벨 효과" 인지 학계 논쟁이 진행 중.
</Callout>

## 결론 — 학술적 미정의 카테고리

본 편이 정리한 5가지 핵심 발견:

1. **AI×Crypto 시총 3년 32배 가속** ($1.8B → $58B). 그러나 카테고리 정의 어려움 (4 framework).
2. **Bittensor 는 "AI 모델 시장"**. 시총 $8.2B 이지만 일 사용량 OpenAI 의 0.3%. utility 의문.
3. **Render 는 "GPU 인프라"**. 실제 GPU 시장 점유율 0.5%. AWS 와 경쟁 시도.
